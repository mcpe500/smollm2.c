# Weight Statistics and Diagnostics

## Overview

This document describes the diagnostic tools and methodologies for analyzing the SmolLM2 C implementation's numerical behavior through all layers.

## Diagnostic Tool: check_layer_trace.c

### Purpose

Provides comprehensive tracing of hidden state values through all transformer layers to identify numerical issues in the inference pipeline.

### Build

```bash
gcc -std=c99 -O3 -Iinclude -o check_layer_trace check_layer_trace.c \
    src/sm2_model.c src/sm2_context.c src/sm2_tokenizer.c \
    src/sm2_rope.c src/sm2_sampling.c src/sm2_rmsnorm.c \
    src/sm2_matmul_ref.c -lm
```

### Usage

```bash
./check_layer_trace [model.sm2] [prompt]
```

Default: `smollm2-135m-f16.sm2` with prompt `"hello"`

## What Gets Traced

### 1. Weight Statistics

At model load time:
- Sample of 1000 values from `tok_embeddings`
- Per-layer samples from: `input_layernorm`, `q_proj`, `k_proj`, `v_proj`, `o_proj`, `gate_proj`, `up_proj`, `down_proj`, `post_attention_layernorm`
- `final_norm` weights

Statistics computed: min, max, mean, std

### 2. Per-Token Traces

Track indices `[0, 10, 100, 200, 500]` through each stage:

| Stage | Description |
|-------|-------------|
| Embedding | Raw token embedding |
| LN1_out | After input RMSNorm |
| Q | Query projection output |
| K | Key projection output |
| V | Value projection output |
| Attn_out | After attention |
| Post_LN | After post-attention RMSNorm |
| Gate | Gate projection (SwiGLU) |
| Up | Up projection (SwiGLU) |
| SiLU | After silu(gate) |
| FFN_out | After FFN + residual |
| Final_LN | After final RMSNorm |

### 3. Logits Analysis

- Range: min, max, mean
- Top 20 logits with token IDs
- Separation analysis (tight vs. spread)

## Common Issues and Diagnostics

### Issue: Logits All Same Value

**Symptoms**: Top 20 logits differ by < 1.0

**Possible causes**:
1. Embedding table not loaded correctly
2. Final RMSNorm producing zero/NAN
3. All weights are zero
4. Matmul producing garbage

**Debug**: Check embedding values directly, verify final_norm scale

### Issue: Hidden States Explode (NaN/Inf)

**Symptoms**: Values become NaN or very large (>1000)

**Possible causes**:
1. Kahan summation bug
2. RMSNorm division by zero
3. Attention scores overflow

**Debug**: Check RMSNorm epsilon (1e-5f), attention score scaling

### Issue: Hidden States Vanish (All Zero/Near-Zero)

**Symptoms**: All hidden states ~0

**Possible causes**:
1. Model weights all zero
2. Wrong layer offset in weight loading
3. Residual connection missing

**Debug**: Verify weight arrays have non-zero values

### Issue: Good Hidden States, Garbled Output

**Symptoms**: Numerical traces look fine but output is nonsense

**Possible causes**:
1. Tokenizer mismatch
2. Logits-to-token mapping wrong
3. BPE byte handling incorrect

**Debug**: Check byte_to_token mapping, decode function

## Interpreting Layer Traces

### Healthy Token Flow ("hello")

```
Token 0 (28120):
  Embedding: [-0.1, 0.2, -0.3, ...]  min=-0.5 max=0.5
  LN1_out:   [-0.2, 0.1, 0.4, ...]   min=-2.0 max=2.0
  Q:         [-0.5, 0.3, -0.1, ...]  min=-3.0 max=3.0
  ...
  FFN_out:   [0.1, -0.2, 0.5, ...]   min=-5.0 max=5.0
  Final_LN:  [0.2, -0.1, 0.3, ...]   min=-2.0 max=2.0
```

### Unhealthy Examples

**Dead model (all zeros)**:
```
  Embedding: [0.0, 0.0, 0.0, ...]
  LN1_out:   [0.0, 0.0, 0.0, ...]
```

**Exploding gradients**:
```
  FFN_out:   [NaN, NaN, NaN, ...]
```

**Noisy/unfocused**:
```
  Logits range: [0.0, 0.001]  (no separation)
```

## Adding Custom Diagnostics

### To trace a new value:

1. Add field to `trace_data` struct
2. Capture value in `traced_layer_forward()`
3. Print in `print_trace_results()`

Example:
```c
// In trace_data
float custom_trace[MAX_TRACE][N_TRACE];

// In traced_layer_forward
if (token_idx < MAX_TRACE) {
    for (int t = 0; t < N_TRACE; t++) {
        td->custom_trace[token_idx][t] = xb_out[trace_indices[t]];
    }
}
```
