# Spec 001: smollm2.c Master Blueprint

## Task/Prompt

Create smollm2.c/smollm2dl - a decode-first SmolLM2 inference engine in portable C with smollm2dl decode layer, flash/block prefill, flash decode, paged KV, KV Turbo Quant ala KIVI, no-allocation decode loop, streaming token, and low-memory 135M Q4 mode for VPS 512 MB; DFlash as optional speculative acceleration.

## Tujuan

Membuat smollm2.c sebagai SmolLM2-family runtime dengan smollm2dl sebagai decode layer yang super optimized untuk inference.

## Kenapa Tujuan Ini

SmolLM2 family (135M, 360M, 1.7B) butuh runtime khusus yang decode-first, bukan generic forward pass. VPS 512MB harus bisa jalan. Server deployment butuh scaling. Ini gap yang tidak ditutup oleh llama.cpp.

## Logic Changes

1. **Model Spec Constants:** Konfigurasi GQA untuk 135M/360M/1.7B.
2. **sm2_context:** Struktur dengan preallocated buffers untuk menghindari runtime allocation.
3. **Core APIs:** `sm2_prefill()` untuk prompt processing dan `sm2_decode_next()` untuk token generation.
4. **Paged KV Cache:** Manajemen memori KV dalam blok/halaman (SM2_KV_PAGE_TOKENS=16).
5. **KV Quantization:** Dukungan F16, Q8, Q4, dan TURBO2 (K per-channel, V per-token).
6. **.sm2 Format:** Header format dengan magic "SM2C001" dan tensor index.
7. **Server Scheduler:** Continuous batching untuk efisiensi throughput server.
8. **Low-memory Mode:** Hard limit RSS untuk environment terbatas seperti VPS 512MB.
9. **DFlash:** Block diffusion speculative decoding (Phase 8b research).

### Phase 8b — DFlash (Research)
DFlash (z-lab/dflash) adalah block diffusion model untuk speculative decoding.

**Inspirasi dari:** https://github.com/z-lab/dflash (4.6k stars)

**Arsitektur DFlash:**
- Lightweight diffusion draft model memprediksi blocks of tokens (~16 tokens/block)
- Target model memverifikasi entire block dalam satu prefill-like pass
- Parallel drafting: generate banyak token sekaligus, bukan autoregressive
- Claims: 6x+ lossless acceleration, 2.5x lebih tinggi dari EAGLE-3

**DFlash untuk smollm2.c:**
- Phase 8b: DFlash block diffusion draft model integration
- Requires: trained DFlash-SmolLM2 draft model (research, tidak otomatis dari checkpoint biasa)
- NOT untuk VPS 512 MB (draft model menambah memory overhead)
- Server/GPU mode only

**DFlash API:**
```c
typedef struct {
    sm2_model *draft_model;
    sm2_model *target_model;
    int num_draft_tokens;      // default: 16
    int block_size;            // DFlash block size: 16
    float accept_threshold;
} sm2_dflash_config;

int sm2_dflash_draft_block(sm2_context *ctx, sm2_dflash_config *cfg, int *out_tokens);
int sm2_dflash_verify_block(sm2_context *ctx, sm2_dflash_config *cfg, 
                           const int *draft_tokens, int n_tokens, int *accept_len);
```

**DFlash Flow:**
```
1. Draft model generate K tokens via block diffusion (parallel)
2. Target model verify K tokens dalam satu prefill-like pass
3. Accept matching prefix
4. On rejection: sample from target distribution
5. Continue dengan next block
```

**Referensi:**
- Paper: arXiv:2602.06036
- Supported backends: vLLM, SGLang, Transformers, MLX

### .sm2 File Format
```c
#define SM2_MAGIC "SM2C001"
#define SM2_VERSION 1

typedef struct {
    char magic[8];
    uint32_t version;
    uint32_t variant_id;
    uint32_t quant_type;
    uint32_t flags;
    uint32_t vocab_size, n_layers, dim, hidden_dim;
    uint32_t n_heads, n_kv_heads, head_dim;
    uint32_t max_seq_len;
    float rms_eps, rope_theta;

    uint64_t tokenizer_offset, tokenizer_size;
    uint64_t tensor_index_offset, tensor_index_size;
    uint64_t weights_offset, weights_size;
    uint64_t checksum;
} sm2_file_header;
```

### KV Page Structure
```c
#define SM2_KV_PAGE_TOKENS 16

typedef enum {
    SM2_KV_F16,
    SM2_KV_Q8,
    SM2_KV_Q4,
    SM2_KV_TURBO2,    // KIVI-like: K per-channel, V per-token
    SM2_KV_MIXED      // recent Q8/F16, older Q4/TURBO2
} sm2_kv_dtype;

typedef struct {
    uint32_t id;
    uint16_t used;      // tokens in use
    uint16_t refcount;  // reference counting
    uint32_t next_free;
    uint8_t *k_data, *v_data;
    uint8_t *k_scale, *v_scale;
} sm2_kv_page;

typedef struct {
    int n_layers, n_kv_heads, head_dim;
    int page_tokens;
    sm2_kv_dtype dtype;
    int max_pages;
    sm2_kv_page *pages;
    uint32_t *free_stack;
    int free_top;
} sm2_kv_pool;

typedef struct {
    uint64_t seq_id;
    int seq_len, n_pages;
    uint32_t page_ids[256];  // max ~4K tokens per sequence
} sm2_kv_table;
```
