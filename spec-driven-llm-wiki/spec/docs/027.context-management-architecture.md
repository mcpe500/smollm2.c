# Context Management Architecture

## Overview

The `sm2_context` struct manages all runtime state for inference, including preallocated scratch buffers, KV cache, generation parameters, and RNG state. It is designed for **zero-allocation in the hot path** - all buffers are allocated once at context creation and reused across prefill and decode phases.

### Key Design Principles

1. **Preallocated buffers**: No malloc/calloc during inference
2. **Ping-pong buffers**: Efficient layer-to-layer data flow
3. **Integrated KV cache**: Cache stored directly in scratch structure
4. **Ring buffer for repetition tracking**: Efficient token history

```c
typedef struct {
    // Activation buffers [dim]
    float* x;           // Input embedding
    float* xb;          // Residual buffer / layer output
```

## Context Creation (`sm2_create_context`)

### Function Signature

```c
int sm2_create_context(sm2_model* model, sm2_context** out_ctx);
```

### Allocation Sequence

```c
int sm2_create_context(sm2_model* model, sm2_context** out_ctx) {
    // 1. Allocate context struct
    sm2_context* ctx = calloc(1, sizeof(sm2_context));
    
    // 2. Initialize basic state
    ctx->model = model;
    ctx->pos = 0;
    ctx->last_token = 1;  // BOS token
    ctx->rng_state = 123456789ULL;
    
    // 3. Calculate dimensions
    int kv_dim = model->n_kv_heads * model->head_dim;
    int max_seq = spec->max_seq_len;
    int n_layers = model->n_layers;
    
    // 4. Allocate scratch buffers (activation memory)
    ctx->scratch.x = calloc(dim, sizeof(float));
    ctx->scratch.xb = calloc(dim, sizeof(float));
    ctx->scratch.q = calloc(dim, sizeof(float));
    ctx->scratch.k = calloc(kv_dim, sizeof(float));
    ctx->scratch.v = calloc(kv_dim, sizeof(float));
    ctx->scratch.attn_out = calloc(dim, sizeof(float));
    ctx->scratch.logits = calloc(vocab, sizeof(float));
    ctx->scratch.xb2 = calloc(hidden * 2, sizeof(float));
    
    // 5. Allocate KV cache (per-layer flat arrays)
    size_t kv_per_layer = n_kv_heads * max_seq * head_dim;
    ctx->scratch.k_cache = calloc(n_layers, sizeof(float*));
    ctx->scratch.v_cache = calloc(n_layers, sizeof(float*));
    for (int l = 0; l < n_layers; l++) {
        ctx->scratch.k_cache[l] = calloc(kv_per_layer, sizeof(float));
        ctx->scratch.v_cache[l] = calloc(kv_per_layer, sizeof(float));
    }
    
    // 6. Allocate repetition penalty buffer
    ctx->scratch.recent_tokens = calloc(max_seq, sizeof(int));
    ctx->scratch.recent_max = max_seq;
    
    // 7. Initialize generation parameters
    ctx->params.temperature = 0.0f;
    ctx->params.top_p = 100;
    // ...
}
```

### Memory Totals (135M)

| Component | Size |
|-----------|------|
| Context struct | ~64 bytes |
| Activation buffers (x, xb, q, k, v, attn_out, xb2) | ~16 KB |
| Logits buffer | ~192 KB |
| KV cache (K + V, 30 layers) | ~360 MB |
| Recent tokens ring buffer | ~32 KB |
| **Total** | **~361 MB** |

## State Management

### Position Tracking

| State Variable | Type | Purpose | Update Location |
|---------------|------|---------|----------------|
| `ctx->pos` | `int` | Current position | `sm2_decode_next` |
| `ctx->last_token` | `int` | Last generated token | Both prefill and decode |
| `ctx->scratch.kv_cache_len` | `int` | Positions in KV cache | After each token |
| `ctx->scratch.recent_head` | `int` | Ring buffer head | Circular |

### Position Updates During Prefill

```c
// sm2_prefill lines 388-417
for (int t = 0; t < n_tokens; t++) {
    int seq_pos = t;
    
    // Process token t through all layers
    for (int layer = 0; layer < model->n_layers; layer++) {
        layer_forward(ctx->scratch.xb, ctx->scratch.x, ...);
    }
    
    // Update state after each token
    ctx->scratch.kv_cache_len = t + 1;
    ctx->last_token = tokens[t];
    ctx->scratch.recent_tokens[t] = tokens[t];
}
```

### Position Updates During Decode

```c
// sm2_decode_next lines 456-521
int seq_pos = ctx->scratch.kv_cache_len;  // Position for new token

// Embed last_token (autoregressive)
embedding_lookup(ctx->scratch.x, ctx->last_token, ...);

// Forward through all layers
for (int layer = 0; layer < ctx->model->n_layers; layer++) {
    layer_forward(...);
}

// Sample token
int token = sm2_sample_token(ctx->scratch.logits, ...);

// Update state
ctx->scratch.kv_cache_len = seq_pos + 1;
ctx->pos++;
ctx->last_token = token;
ctx->scratch.recent_tokens[seq_pos] = token;
```

### State Flow Diagram

```
                    +------------------+
                    |   sm2_context    |
                    +------------------+
                    | model: *        |
                    | pos: 0          |
                    | last_token: 1  |
                    | rng_state: ...  |
                    | params: {...}   |
                    +------------------+
                           |
                    +------+-------+
                    |              |
                    v              v
            +-------------+  +--------------+
            | sm2_scratch |  | sm2_kv_table |
            +-------------+  +--------------+
            | x, xb, xb2 |  | seq_id       |
            | q, k, v    |  | seq_len      |
            | attn_out   |  | page_ids[]   |

            | k_cache[]  |
            | v_cache[]  |
            | kv_cache_len
            | recent_tokens
            +-------------+

                    INFERENCE FLOW
                    ==============

    PREFILL: tokens[] -> embedding -> layers -> logits
    DECODE:  last_token -> embedding -> layers -> logits -> sample -> new_token
```

## Ping-Pong Buffer Strategy

### Buffer Swapping

The `x` and `xb` buffers are used in alternating fashion between layers:

```c
// sm2_prefill and sm2_decode_next
for (int layer = 0; layer < n_layers; layer++) {
    // xb_out = layer(x_in)
    layer_forward(ctx->scratch.xb, ctx->scratch.x, layer, ...);
    
    // Swap: output becomes next layer's input
    float* tmp = ctx->scratch.x;
    ctx->scratch.x = ctx->scratch.xb;
    ctx->scratch.xb = tmp;
}
```

### Buffer States During Layer Forward

```
Before layer 0:  x = input_embedding, xb = ?
                -> layer_forward(xb, x)
                -> xb = layer_0_output

After swap:     x = layer_0_output, xb = ?
                -> layer_forward(xb, x)
                -> xb = layer_1_output

After layer 29: x = layer_29_output (final)
                xb = layer_28_output (discarded)
```

### Scratch Buffer Usage by Function

| Buffer | `layer_forward` | `sm2_prefill` | `sm2_decode_next` |
|--------|---------------|---------------|-------------------|
| `x` | Input | Input/Output | Input/Output |
| `xb` | Output | Ping-pong | Ping-pong |
| `q` | Q projection output | Reused | Reused |
| `k` | K projection output | Reused | Reused |
| `v` | V projection output | Reused | Reused |
| `attn_out` | Attention output | Reused | Reused |
| `xb2` | FFN workspace | Reused | Reused |

## KV Cache Integration

### Cache Structure

```c
// sm2_scratch fields for KV cache
float** k_cache;    // [n_layers][n_kv_heads * max_seq * head_dim]
float** v_cache;   // [n_layers][n_kv_heads * max_seq * head_dim]
int kv_cache_len;   // Number of positions stored
```

### Cache Layout

```
k_cache[layer] = flat array of n_kv_heads * max_seq * head_dim floats

Layout within layer:
[ head_0_pos_0_0 .. head_0_pos_0_63 ][ head_0_pos_1_0 .. head_0_pos_1_63 ]...
[ head_1_pos_0_0 .. head_1_pos_0_63 ][ head_1_pos_1_0 .. head_1_pos_1_63 ]...
[ head_2_pos_0_0 .. head_2_pos_0_63 ][ head_2_pos_1_0 .. head_2_pos_1_63 ]...

Index formula: head * max_seq * head_dim + pos * head_dim + d
```

### Cache Indexing (from `layer_forward` lines 271-279)

```c
// Store K/V at current position
int kv_head_dim = model->head_dim;
for (int head = 0; head < model->n_kv_heads; head++) {
    for (int d = 0; d < kv_head_dim; d++) {
        int cache_idx = head * ctx->params.max_context * kv_head_dim
                     + seq_pos * kv_head_dim + d;
        ctx->scratch.k_cache[layer][cache_idx] = k[head * kv_head_dim + d];
        ctx->scratch.v_cache[layer][cache_idx] = v[head * kv_head_dim + d];
    }
}
```

### Attention with Cache (from `attention_with_cache` lines 128-177)

```c
// seq_pos is kv_cache_len (position after cached tokens)
// kv_seq includes current position
int kv_seq = ctx->scratch.kv_cache_len + 1;

// For each query head, compute attention over all cached positions
for (int qh = 0; qh < n_heads; qh++) {
    int kv_head = qh / group_size;
    
    // Compute scores for all positions
    for (int pos = 0; pos < kv_seq; pos++) {
        // dot product with cached K
        int cache_idx = kv_head * max_context * head_dim + pos * head_dim + d;
        float kv = ctx->scratch.k_cache[layer][cache_idx];
        dot += qv * kv;
    }
    
    // Weighted sum with cached V
    for (int d = 0; d < head_dim; d++) {
        float sum = 0.0f;
        for (int pos = 0; pos < kv_seq; pos++) {
            int cache_idx = ...;
            float vv = ctx->scratch.v_cache[layer][cache_idx];
            sum += scores[pos] * vv;
        }
        out[qh * head_dim + d] = sum / sum_exp;
    }
}
```

## Repetition Penalty Tracking

### Ring Buffer Structure

```c
// sm2_scratch fields
int* recent_tokens;  // Ring buffer of token IDs
int recent_head;     // Current head position
int recent_max;      // Maximum buffer size
```

### Writing Tokens

```c
// During prefill
ctx->scratch.recent_tokens[t] = tokens[t];

// During decode
ctx->scratch.recent_tokens[seq_pos] = token;
```

### Ring Buffer Access Pattern

```
Initial state: recent_head = 0
After 5 tokens: recent_head = 5

Buffer contents:
[0] = token_0
[1] = token_1
[2] = token_2
[3] = token_3
[4] = token_4
[5..max-1] = unused

Access recent N tokens:
for (int i = 0; i < penalty_window; i++) {
    int idx = (recent_head - 1 - i + recent_max) % recent_max;
    int token = recent_tokens[idx];
    // Apply penalty
}
```

### Repetition Penalty Application (in `sm2_sampling.c`)

```c
// Check against recent tokens
if (params->repetition_penalty != 1.0f) {
    for (int i = 0; i < params->penalty_window; i++) {
        int check_pos = (ctx->scratch.recent_head - 1 - i + ctx->scratch.recent_max)
                      % ctx->scratch.recent_max;
        int token = ctx->scratch.recent_tokens[check_pos];
        if (token >= 0 && token < vocab_size) {
            if (logits[token] > 0) {
                logits[token] /= repetition_penalty;
            } else {
                logits[token] *= repetition_penalty;
            }
        }
    }
}
```

## Context Cleanup (`sm2_free_context`)

### Deallocation Order

```c
int sm2_free_context(sm2_context* ctx) {
    if (!ctx) return 0;
    
    // 1. Free activation buffers
    free(ctx->scratch.x);
    free(ctx->scratch.xb);
    free(ctx->scratch.q);
    free(ctx->scratch.k);
    free(ctx->scratch.v);
    free(ctx->scratch.attn_out);
    free(ctx->scratch.logits);
    free(ctx->scratch.xb2);
    
    // 2. Free repetition penalty buffer
    free(ctx->scratch.recent_tokens);
    
    // 3. Free KV cache per layer
    if (ctx->scratch.k_cache) {
        for (int l = 0; l < ctx->model->n_layers; l++) {
            free(ctx->scratch.k_cache[l]);
            free(ctx->scratch.v_cache[l]);
        }
        free(ctx->scratch.k_cache);
        free(ctx->scratch.v_cache);
    }
    
    // 4. Free context struct
    free(ctx);
    return 0;
}
```

## Inference Flow with Context

### Full Inference Pipeline

```
1. LOAD MODEL
   sm2_model* model;
   sm2_load_model("model.sm2", &model);

2. CREATE CONTEXT
   sm2_context* ctx;
   sm2_create_context(model, &ctx);
   // Now: pos=0, last_token=BOS, kv_cache_len=0, buffers allocated

3. SET GENERATION PARAMS (optional)
   ctx->params.temperature = 0.7f;
   ctx->params.top_p = 90;
   ctx->params.repetition_penalty = 1.1f;

4. ENCODE PROMPT
   int tokens[MAX_TOKENS];
   int n = sm2_tokenizer_encode(tok, prompt, tokens, MAX_TOKENS);

5. PREFILL
   sm2_prefill(ctx, tokens, n);
   // After: kv_cache_len=n, last_token=tokens[n-1]

6. DECODE LOOP
   for (int i = 0; i < max_new_tokens; i++) {
       int token;
       sm2_decode_next(ctx, &token);
       if (token == EOS) break;
       output_ids[i] = token;
   }

7. DECODE TEXT
   char* text = sm2_tokenizer_decode(tok, output_ids, n_output);

8. FREE CONTEXT
   sm2_free_context(ctx);
```

## Thread Safety Considerations

### Current State: Not Thread-Safe

The `sm2_context` is designed for single-threaded inference. For multi-threaded use:

1. **Each thread needs its own context** - KV cache and scratch buffers are per-context
2. **Model weights are read-only** - Safe to share across threads
3. **Tokenizer state is shared** - `sm2_tokenizer` is read-only after init

### Recommended Pattern

```c
// Main thread: load model once
sm2_model* model;
sm2_load_model("model.sm2", &model);

// Per-thread: create separate context
void* thread_func(void* arg) {
    sm2_context* ctx;
    sm2_create_context(model, &ctx);  // Each thread has own context
    
    // Use ctx for inference
    
    sm2_free_context(ctx);  // Clean up per thread
    return NULL;
}
```
