# 012: Prefill and Decode Loop Architecture

> Precise buffer flow, ping-pong mechanics, residual paths, and where every value lives.

---

## 1. Buffer Memory Layout

All scratch buffers are preallocated once at context creation time (no malloc in hot path):

```
ctx->scratch.x       [dim]           // primary ping-pong buffer
ctx->scratch.xb      [dim]           // secondary ping-pong buffer
ctx->scratch.q       [dim]           // Q projection output
ctx->scratch.k       [kv_dim]        // K projection output
ctx->scratch.v       [kv_dim]        // V projection output
ctx->scratch.attn_out [dim]          // attention output
ctx->scratch.xb2     [hidden_dim * 2]// SwiGLU gate + up workspace
ctx->scratch.logits  [vocab_size]    // final logits
ctx->scratch.k_cache [n_layers][n_kv_heads][max_seq][head_dim]
ctx->scratch.v_cache [n_layers][n_kv_heads][max_seq][head_dim]
ctx->scratch.recent_tokens [max_seq] // ring buffer for repetition penalty
```

Key invariant: `layer_forward()` takes `xb_out` and `x_in` as **explicit pointer arguments**. It does **not** reference `ctx->scratch.x` or `ctx->scratch.xb` internally. This makes the ping-pong contract explicit at the call site.

## 2. `layer_forward()` — Single Transformer Block

Signature:
```c
static void layer_forward(float* xb_out, const float* x_in, int layer,
                          sm2_model* model, sm2_context* ctx, int seq_pos)
```

### 2.1 Step-by-step State of Each Buffer

| Step | Operation | `xb_out` (output) | `x_in` | `q`, `k`, `v`, `attn_out` | `ffn_temp` |
|------|-----------|-------------------|--------|---------------------------|------------|
| 0    | INPUT | **undefined** | **valid** (e.g. embedding or prev layer output) | undefined | undefined |
| 1    | RMSNorm on `x_in` | normalized `x_in` | unchanged | undefined | undefined |
| 2    | Q proj | **overwritten** with Q | unchanged | q populated | undefined |
| 3    | K proj | **overwritten** with Q (only q is clobbered) | unchanged | k populated | undefined |
| 4    | V proj | **overwritten** with Q (only q is clobbered) | unchanged | v populated | undefined |
| 5    | RoPE on `q`, `k` | unchanged | unchanged | q, k rotated | undefined |
| 6    | Store K/V to cache | unchanged | unchanged | unchanged | unchanged |
| 7    | `attention_with_cache` | **overwritten** with attn output | unchanged | attn_out populated, q/k/v read | undefined |
| 8    | O proj | **overwritten** with O projection result | unchanged | attn_out read | undefined |
| 9    | Residual add | `xb_out[i] += x_residual[i]` | unchanged | — | — |
| 10   | Save post-attn | `x_post_attn[i] = xb_out[i]` | unchanged | — | — |
| 11   | Post-attn RMSNorm | normalized post-attn | unchanged | — | — |
| 12   | gate proj | **overwritten** with gate | unchanged | — | `ffn_temp[0..hidden_dim-1]` |
| 13   | up proj | unchanged (overwritten with up) | unchanged | — | `ffn_temp[hidden_dim..2*hidden_dim-1]` |
| 14   | SiLU gate | `ffn_temp[0..hidden_dim-1] *= sigmoid` | unchanged | — | gate now gated |
| 15   | `gate *= up` | unchanged | unchanged | — | `ffn_temp[0..hidden_dim-1]` now has elementwise product |
| 16   | down proj + FFN residual | `xb_out[i] = x_post_attn[i] + down_output` | unchanged | — | `ffn_temp` read as elementwise product |

**Exit state**: `xb_out` holds the final output of this layer. `x_in` is unchanged throughout.

### 2.2 Residual Connections Within One Layer

SmolLM2 uses **two residual connections per block**:

1. **Attention residual** (step 9): `xb_out += x_residual` where `x_residual = x_in`
   - After O projection, the attention output is added back to the original input.
   - This is the standard pre-norm formulation: `output = Input + Attention(LN(Input))`

2. **FFN residual** (step 16): `xb_out[i] = x_post_attn[i] + down_output`
   - The pre-norm variant: `output = PreAttn(Input) + FFN(LN(PreAttn(Input)))`
   - There is **no** residual around the entire block (Layer 29 output is the block output, not block_output + x_in).

The architecture is pre-norm (RMSNorm **before** each sub-layer), not post-norm:
```
x = x_in
x = x + Attention(LN(x))
x = x + FFN(LN(x))
return x
```

## 3. Ping-Pong Buffer Swap Contract

The caller of `layer_forward` manages the swap:

```c
for (int layer = 0; layer < model->n_layers; layer++) {
    layer_forward(ctx->scratch.xb, ctx->scratch.x, ...);  // read x, write xb
    float* tmp = ctx->scratch.x;
    ctx->scratch.x = ctx->scratch.xb;
    ctx->scratch.xb = tmp;
}
```

### Why this produces the correct final state in `scratch.x`

After **N** layers with N swaps:

- Layer 0 input: `x[0]` (embedding) → Layer 0 output: `xb` → **swap** → `x = xb`, `xb = x(0)`
- Layer 1 input: `x[1]` (Layer 0 output) → Layer 1 output: `xb` → **swap** → `x = xb`, `xb = x(1)`
- ...
- Layer 29 input: `x[29]` (Layer 28 output) → Layer 29 output: `xb` → **swap** → `x = xb`, `xb = x(29)`

After the final swap (the swap that follows Layer 29):
- `ctx->scratch.x` holds the output of Layer 29.
- `ctx->scratch.xb` holds the embedding for token t (the `xb` that was swapped out).

So **after all layers and the final swap, `scratch.x` contains the final hidden state.**

## 4. `sm2_prefill()` Flow

```
Input: tokens[0..n_tokens-1]
Output: logits over vocab (final token only)
```

### 4.1 Per-Token Loop

For each token index `t` in `[0, n_tokens-1]`:

1. **Embedding lookup**: `embedding_lookup(ctx->scratch.x, tokens[t], tok_embeddings)`
   - Writes token embedding into `ctx->scratch.x`.
   - `ctx->scratch.xb` is whatever was left over from the previous iteration.

2. **Layer loop** (30 iterations):
   - `layer_forward(ctx->scratch.xb, ctx->scratch.x, layer, model, ctx, seq_pos=t)`
   - **Then swap**: `x ↔ xb`
   - After all 30 layers and the final swap: `ctx->scratch.x` holds the hidden state for token `t`.

3. **KV cache state update**:
   - `ctx->scratch.kv_cache_len = t + 1`
   - Each `layer_forward` call already stored K/V at `seq_pos = t` (step 6 inside layer_forward).

4. **Context state update**:
   - `ctx->last_token = tokens[t]` — updated to the **last** prompt token on each iteration, so after the loop it is `tokens[n_tokens-1]`.

5. **Repetition penalty tracking**:
   - `ctx->scratch.recent_tokens[t] = tokens[t]`

### 4.2 After All Tokens

6. **Final RMSNorm** (one-time, on `ctx->scratch.x`):
   ```c
   float* final_h = ctx->scratch.x;
   rms_norm(final_h, model->final_norm, model->dim);
   ```
   - Normalizes the hidden state of the **last prompt token**.
   - Overwrites `ctx->scratch.x` in-place.

7. **Logits computation** (one-time, on `ctx->scratch.x`):
   ```c
   float* final_h = ctx->scratch.x;
   for (i in vocab):
       logits[i] = dot(final_h, tok_embeddings.row[i])
   ```
   - `ctx->scratch.logits` is populated with the final token's logits.

### 4.3 Prefill Summary Table

| Step | Token 0 | Token 1 | ... | Token n-1 |
|------|---------|---------|-----|-----------|
| Embed into | `scratch.x` | `scratch.x` | ... | `scratch.x` |
| After 30 layers + swap, hidden in | `scratch.x` | `scratch.x` | ... | `scratch.x` |
| KV cache populated at | seq_pos=0 | seq_pos=1 | ... | seq_pos=n-1 |
| `last_token` set to | tokens[0] | tokens[1] | ... | **tokens[n-1]** |
| Final RMSNorm applied | No | No | No | **Yes** |
| Logits computed | No | No | No | **Yes** |

## 5. `sm2_decode_next()` Flow

```
Input: none (uses ctx->last_token, kv_cache)
Output: next generated token
```

1. **Compute seq_pos**: `seq_pos = ctx->scratch.kv_cache_len`
   - This is the position right after the last cached token.

2. **Embedding lookup**: `embedding_lookup(ctx->scratch.x, ctx->last_token, tok_embeddings)`
   - Writes the embedding of the **last generated token** into `ctx->scratch.x`.
   - This is the only new information — all previous tokens are already in the KV cache.

3. **Layer loop** (30 iterations, identical ping-pong as prefill):
   - `layer_forward(ctx->scratch.xb, ctx->scratch.x, layer, model, ctx, seq_pos)`
   - **Then swap**: `x ↔ xb`
   - After all 30 layers: `ctx->scratch.x` holds the hidden state for the new token.

4. **Final RMSNorm** (on `ctx->scratch.x`):
   - In-place normalization of the new token's hidden state.

5. **Logits computation** (on `ctx->scratch.x`):
   - `ctx->scratch.logits[i] = dot(final_h, tok_embeddings.row[i])`

6. **Sampling**:
   - `token = sm2_sample_token(ctx->scratch.logits, ...)`
   - Uses `ctx->scratch.recent_tokens` for repetition penalty.

7. **Repetition penalty tracking**:
   - `ctx->scratch.recent_tokens[ctx->scratch.kv_cache_len] = token`
   - Records the generated token at the position it will occupy in the sequence.

8. **Context state update**:
   - `ctx->scratch.kv_cache_len = seq_pos + 1` (advance by 1)
   - `ctx->pos++`
   - `ctx->last_token = token`
   - `*out_token = token`

## 6. The Ping-Pong Bug Risk — Final Hidden State Location

There is a subtle but critical invariant here that deserves its own section.

### The Risk

Inside `sm2_decode_next`, there is a comment:
```c
// Note: After the loop, xb_out is in ctx->scratch.xb (last swap puts output there)
```

This comment is **INCORRECT** for the final hidden state. The actual final hidden state is in `ctx->scratch.x`, not `ctx->scratch.xb`.

The confusion arises because:
- `layer_forward` writes its output to `xb_out` (the **first** argument).
- After each `layer_forward` call, the swap `x ↔ xb` is executed.
- This means `xb_out` (the write target) does **NOT** hold the output after the swap.

### Correct Final State Location

| Location | After Layer 29 call | After Layer 29 swap |
|----------|--------------------|--------------------|
| `ctx->scratch.x` | input to Layer 29 | **Layer 29 output** (final hidden state) |
| `ctx->scratch.xb` | **Layer 29 output** | input to Layer 29 (old embedding) |

The final hidden state is in `ctx->scratch.x` **after** the swap. The code correctly reads from `ctx->scratch.x` for the final RMSNorm and logits computation (lines 479-504).

## 7. Embedding Tied Weight Architecture

SmolLM2 uses `tie_word_embeddings = True`. This means:

```
tok_embeddings.weight == output.weight   (same memory, same matmul)
```

In the implementation, this means **the same `tok_embeddings` table** is used for both:
1. Token embedding lookup (input: token ID → output: hidden vector)
2. Logits computation (input: hidden vector → output: vocab logits via matmul with `tok_embeddings`)

### The Tie Weight Implication

In a standard transformer without tied weights:
```
logits = LN(h_last) @ output.weight^T
```

With `tie_word_embeddings = True` and pre-norm (RMSNorm **after** all layers, not before the first):
```
logits = LN(h_last) @ tok_embeddings.weight^T
```

This is exactly what the code does — it reuses `model->tok_embeddings->data` for both the forward embedding lookup and the backward logits matmul.

**No explicit residual from the embedding is added** in this model. The architecture is:
1. `h_0 = Embed(token)`
2. For each layer i: `h_i = Block(h_{i-1})`
3. `logits = LN(h_N) @ Embed.weight^T`

The "tie" is that `Embed.weight` is shared between step 1 and step 3, not that there is a residual around all layers.

## 8. Full Residual Path Through the Model

```
token[0] → Embed() → x (hidden_dim)
                   ↓
            Layer 0: x = x + Attn(LN(x)) + FFN(LN(x))
            Layer 1: x = x + Attn(LN(x)) + FFN(LN(x))
            ...
            Layer 29: x = x + Attn(LN(x)) + FFN(LN(x))
                   ↓
            Final RMSNorm(x) → logits = x @ Embed.weight^T
```

Within each layer, the residual flow is:

```
x_in (saved as x_residual)
  ↓
LN → Q,K,V → RoPE → attention → O_proj → + x_residual → LN → gate/up → SiLU(gate)*up → down_proj → + x_post_attn
                                                                                              ↑
                                                                                     this is the attention residual
```

**There is no residual connection from the embedding input around the entire transformer stack.** The only residuals are within each individual transformer block (one for attention, one for FFN).

## 9. KV Cache Mechanics

The KV cache stores per-layer, per-head, per-position K and V vectors:

```
k_cache[layer][kv_head][pos][head_dim]
v_cache[layer][kv_head][pos][head_dim]
```

- **Prefill**: Each token t at seq_pos = t stores its K/V to all layers.
- **Decode**: The single new token at seq_pos = kv_cache_len stores its K/V.
- **Attention**: `attention_with_cache` reads from pos=0 through pos=kv_seq (inclusive) to attend over the full cached context.
  - `kv_seq = ctx->scratch.kv_cache_len + 1` accounts for the fact that K/V were stored before the attention call.

## 10. Critical Invariants Summary

1. `layer_forward(xb_out, x_in, ...)` writes to `xb_out`, reads from `x_in`. `x_in` is never modified.
2. After `layer_forward` returns, `xb_out` holds the layer output. The swap makes this become the next layer's input.
3. After the full layer loop and final swap, `ctx->scratch.x` holds the final hidden state.
4. Final RMSNorm and logits computation **must** use `ctx->scratch.x` (not `ctx->scratch.xb`).
5. `ctx->last_token` always tracks the last token in the full sequence (last prompt token during prefill, last generated token during decode).
6. `ctx->scratch.kv_cache_len` always tracks the number of tokens currently in the KV cache.
7. The same `tok_embeddings` table is used for both embedding and logits — this is the tied embedding architecture.
8. No main residual around all layers — the transformer blocks are pre-norm and the embedding is not added back at the end.
