# 012: Prefill and Decode Loop Architecture

> Implementation-accurate forward pass flow, buffer reuse, ping-pong mechanics, and residual paths.

---

## 0. Implementation Overview

The actual implementation is a single-file design in `src/sm2_context.c`. The codebase provides three forward entry points:

| Function | Purpose | Input |
|----------|---------|-------|
| `sm2_prefill()` | Process entire prompt | tokens[0..n-1] |
| `sm2_decode_next()` | Generate single token | ctx->last_token |
| `sm2_decode_stream()` | Wrapper for streaming | max_new_tokens |

All paths use preallocated buffers from `ctx->scratch` — no runtime malloc/free in hot path.

---

## 1. Buffer Memory Layout

```c
ctx->scratch.x       [dim]           // ping-pong input buffer
ctx->scratch.xb      [dim]           // ping-pong output buffer
ctx->scratch.q       [dim]           // Q projection output
ctx->scratch.k       [kv_dim]        // K projection output
ctx->scratch.v       [kv_dim]        // V projection output
ctx->scratch.attn_out [dim]          // attention output
ctx->scratch.xb2     [hidden_dim * 2]// SwiGLU gate + up workspace
ctx->scratch.logits  [vocab_size]    // final logits
ctx->scratch.k_cache [n_layers][n_kv_heads][max_seq][head_dim]
ctx->scratch.v_cache [n_layers][n_kv_heads][max_seq][head_dim]
ctx->scratch.recent_tokens [max_seq] // ring buffer for repetition penalty
```

**Critical invariant**: `layer_forward(xb_out, x_in, ...)` takes explicit buffer pointers. It reads from `x_in`, writes to `xb_out`. The `ctx->scratch.x`/`xb` are caller's ping-pong buffers, not referenced internally.

## 2. `layer_forward()` — Single Transformer Block

```c
static void layer_forward(float* xb_out, const float* x_in, int layer,
                          sm2_model* model, sm2_context* ctx, int seq_pos)
```

### 2.1 Step-by-step Buffer State

| Step | Operation | `xb_out` | `x_in` | `q`, `k`, `v`, `attn_out` |
|------|-----------|----------|--------|---------------------------|
| 0 | INPUT | undefined | **valid** | undefined |
| 1 | RMSNorm on x_in | normalized x_in | unchanged | undefined |
| 2 | Q proj (overwrite xb_out) | **Q result** | unchanged | q populated |
| 3 | K proj (overwrite xb_out) | Q clobbered | unchanged | k populated |
| 4 | V proj (overwrite xb_out) | Q clobbered | unchanged | v populated |
| 5 | RoPE on q, k | unchanged | unchanged | q, k rotated |
| 6 | Store K/V to cache | unchanged | unchanged | unchanged |
| 7 | attention_with_cache | unchanged | unchanged | **attn_out populated** |
| 8 | O proj (overwrite xb_out) | **O result** | unchanged | attn_out read |
| 9 | Residual add: xb_out += x_in | attention output + residual | unchanged | — |
| 10 | Save x_post_attn | saved for FFN residual | unchanged | — |
| 11 | Post-attn RMSNorm on xb_out | normalized | unchanged | — |
| 12 | SwiGLU: gate/up proj | gate/up in xb2 | unchanged | — |
| 13 | SiLU(gate) * up | gated activation in xb2 | unchanged | — |
| 14 | down proj + FFN residual | **final layer output** | unchanged | — |

**Exit state**: `xb_out` holds layer output. `x_in` is never modified.

### 2.2 Residual Connections Within One Layer

Pre-norm architecture (RMSNorm **before** each sub-layer):

```
x = x_in
x = x + Attention(LN(x))      // residual at step 9
x = x + FFN(LN(x))            // residual at step 14
return x
```

Two residuals per block:
1. **Attention residual** (step 9): `xb_out += x_residual` where `x_residual = x_in`
2. **FFN residual** (step 14): `xb_out = x_post_attn + down_output`

### 2.3 Numerical Stability: Kahan Summation

All matmul operations use Kahan (compensated) summation for reduced floating-point error:

```c
float sum = 0.0f;
float c = 0.0f;
for (int j = 0; j < dim; j++) {
    float y = xb_out[j] * w - c;
    float t = sum + y;
    c = (t - sum) - y;
    sum = t;
}
q[i] = sum;
```

## 3. Ping-Pong Buffer Swap Contract

```c
for (int layer = 0; layer < model->n_layers; layer++) {
    layer_forward(ctx->scratch.xb, ctx->scratch.x, ...);  // read x, write xb
    float* tmp = ctx->scratch.x;
    ctx->scratch.x = ctx->scratch.xb;
    ctx->scratch.xb = tmp;
}
```

After N layers with N swaps, `ctx->scratch.x` holds the final hidden state.

### Why this produces the correct final state in `scratch.x`

- Layer 0 input: `x` (embedding) → Layer 0 output: `xb` → **swap** → `x = xb`, `xb = x(0)`
- Layer 1 input: `x` (Layer 0 output) → Layer 1 output: `xb` → **swap** → `x = xb`, `xb = x(1)`
- ...
- Layer N-1 input: `x` (Layer N-2 output) → Layer N-1 output: `xb` → **swap** → `x = xb`

After the final swap: `ctx->scratch.x` holds the output of Layer N-1.

## 4. `sm2_prefill()` Flow

```
Input: tokens[0..n_tokens-1]
Output: logits over vocab (final token only)
```

### 4.1 Per-Token Loop

For each token index `t` in `[0, n_tokens-1]`:

1. **Embedding lookup**: `embedding_lookup(ctx->scratch.x, tokens[t], tok_embeddings)`

2. **Layer loop**:
   ```c
   for (int layer = 0; layer < model->n_layers; layer++) {
       layer_forward(ctx->scratch.xb, ctx->scratch.x, layer, model, ctx, seq_pos=t);
       // Swap
       float* tmp = ctx->scratch.x;
       ctx->scratch.x = ctx->scratch.xb;
       ctx->scratch.xb = tmp;
   }
   ```
   After all layers + final swap: `ctx->scratch.x` holds hidden state for token t.

3. **State update**:
   - `ctx->scratch.kv_cache_len = t + 1`
   - `ctx->last_token = tokens[t]`
   - `ctx->scratch.recent_tokens[t] = tokens[t]`

### 4.2 After All Tokens (one-time)

5. **Final RMSNorm** (on `ctx->scratch.x`):
   ```c
   rms_norm(final_h, model->final_norm, model->dim);
   ```

6. **Logits computation**:
   ```c
   logits[i] = dot(final_h, tok_embeddings.row[i])  // tied weights
   ```

### 4.3 Prefill Summary

| Step | Token 0 | Token 1 | ... | Token n-1 |
|------|---------|---------|-----|-----------|
| Embed into | `scratch.x` | `scratch.x` | ... | `scratch.x` |
| After N layers + swap, hidden in | `scratch.x` | `scratch.x` | ... | `scratch.x` |
| KV cache populated at | seq_pos=0 | seq_pos=1 | ... | seq_pos=n-1 |
| `last_token` set to | tokens[0] | tokens[1] | ... | **tokens[n-1]** |
| Final RMSNorm applied | No | No | No | **Yes** |
| Logits computed | No | No | No | **Yes** |

## 5. `sm2_decode_next()` Flow

```
Input: ctx->last_token (last generated token)
Output: next generated token
```

1. **Compute seq_pos**: `seq_pos = ctx->scratch.kv_cache_len`

2. **Embedding lookup**: `embedding_lookup(ctx->scratch.x, ctx->last_token, tok_embeddings)`

3. **Layer loop** (identical ping-pong as prefill):
   ```c
   for (int layer = 0; layer < ctx->model->n_layers; layer++) {
       layer_forward(ctx->scratch.xb, ctx->scratch.x, layer, ctx->model, ctx, seq_pos);
       float* tmp = ctx->scratch.x;
       ctx->scratch.x = ctx->scratch.xb;
       ctx->scratch.xb = tmp;
   }
   ```
   After all layers + swap: `ctx->scratch.x` holds hidden state for new token.

4. **Final RMSNorm** (on `ctx->scratch.x`)

5. **Logits computation** (on `ctx->scratch.x`)

6. **Sampling**:
   ```c
   token = sm2_sample_token(ctx->scratch.logits, &ctx->params, &ctx->rng_state, ctx);
   ```

7. **Repetition penalty tracking**:
   ```c
   ctx->scratch.recent_tokens[ctx->scratch.kv_cache_len] = token;
   ```

8. **State update**:
   - `ctx->scratch.kv_cache_len = seq_pos + 1`
   - `ctx->pos++`
   - `ctx->last_token = token`
   - `*out_token = token`

## 6. Final Hidden State Location

After the layer loop and final swap, the final hidden state is in `ctx->scratch.x` (NOT `xb`). This is because:
- `layer_forward` writes output to `xb_out` (first arg)
- Swap executes: `x ↔ xb`
- After swap: `x` holds the output

The comment in the code says:
```c
// Note: After the loop, xb_out is in ctx->scratch.xb (last swap puts output there)
```
This is **misleading** — the final hidden state is correctly in `ctx->scratch.x` as used by the subsequent RMSNorm and logits computation (lines 479-504).

| Location | After last layer call | After last swap |
|----------|----------------------|-----------------|
| `ctx->scratch.x` | input to last layer | **layer output** (final hidden state) |
| `ctx->scratch.xb` | **layer output** | input to last layer (old data) |

## 7. Embedding Tied Weight Architecture

SmolLM2 uses `tie_word_embeddings = True`:

```
tok_embeddings.weight == output.weight   (same memory, same matmul)
```

The same `tok_embeddings` table is used for:
1. Token embedding lookup (token ID -> hidden vector)
2. Logits computation (hidden vector -> vocab logits via matmul)

Architecture:
```
h_0 = Embed(token)
for each layer i: h_i = Block(h_{i-1})
logits = LN(h_N) @ Embed.weight^T
```

**No main residual around entire transformer stack.** The "tie" means `Embed.weight` is shared between embedding and logits, not that there is a residual around all layers.

## 8. Full Residual Path Through the Model

```
token → Embed() → x (dim)
                    ↓
             Layer 0: x = x + Attn(LN(x)) + FFN(LN(x))
             Layer 1: x = x + Attn(LN(x)) + FFN(LN(x))
             ...
             Layer N-1: x = x + Attn(LN(x)) + FFN(LN(x))
                    ↓
             Final RMSNorm(x) → logits = x @ Embed.weight^T
```

Within each layer:
```
x_in (saved as x_residual)
  ↓
LN → Q,K,V → RoPE → attention → O_proj → + x_residual → LN → gate/up → SiLU*up → down_proj → + x_post_attn
```

## 9. KV Cache Mechanics

```
k_cache[layer][kv_head][pos][head_dim]
v_cache[layer][kv_head][pos][head_dim]
```

- **Prefill**: Each token t stores K/V at seq_pos = t (via step 6 inside `layer_forward`)
- **Decode**: New token stores K/V at seq_pos = kv_cache_len
- **Attention**: `attention_with_cache` reads pos 0 through kv_cache_len (inclusive)

```c
int kv_seq = ctx->scratch.kv_cache_len + 1;
```

### GQA Attention (Groups = n_heads / n_kv_heads)

```
For each query head qh:
    kv_head = qh / group_size

    # Compute scores over all cached positions
    for pos in [0, kv_seq):
        scores[pos] = q[qh] @ k[kv_head, pos] / sqrt(head_dim)

    # Softmax
    scores = softmax(scores)

    # Weighted sum of values
    attn_out[qh] = sum(scores[pos] * v[kv_head, pos])
```

## 10. SwiGLU FFN Implementation

The FFN uses SwiGLU activation (Sharded Gate Linear Unit):

```c
// Gate and up projections
gate_out = xb_out @ gate_proj.T   // [hidden_dim]
up_out   = xb_out @ up_proj.T     // [hidden_dim]

// SiLU activation: gate * sigmoid(gate)
for (i in hidden_dim):
    gate_out[i] *= 1.0f / (1.0f + expf(-gate_out[i]))

// Elementwise multiply
gate_out[i] *= up_out[i]

// Down projection + FFN residual
xb_out[i] = x_post_attn[i] + sum_j(gate_out[j] * down_proj[i, j])
```

This replaces traditional GELU/ReLU FFN with a gated activation.

## 11. Prefill vs Decode Comparison

| Aspect | Prefill | Decode |
|--------|---------|--------|
| Tokens processed | All prompt tokens (per-token loop) | Single token per call |
| KV cache | Populated for full context | Extended by 1 token |
| Layer loop | Processes all layers per token | Identical |
| Hot path alloc | None | None |
| Final RMSNorm + logits | After all tokens | After each token |

---

## 12. Critical Invariants Summary

1. `layer_forward(xb_out, x_in, ...)` writes to `xb_out`, reads from `x_in`. `x_in` is never modified.
2. After `layer_forward` returns, caller swaps ping-pong buffers.
3. After full layer loop and final swap, `ctx->scratch.x` holds final hidden state.
4. Final RMSNorm and logits computation must use `ctx->scratch.x`.
5. `ctx->last_token` tracks last token in sequence (last prompt during prefill, last generated during decode).
6. `ctx->scratch.kv_cache_len` tracks number of tokens in KV cache.
7. Same `tok_embeddings` used for embedding and logits (tied weights).
8. No main residual around all layers — pre-norm architecture within each block.
9. All matmuls use Kahan summation for numerical stability.
10. KV cache stores per-layer, per-head, per-position K/V for O(1) context retrieval during decode.
