## Verification Results

### Conversion Format

- **Source:** HuggingFace safetensors (BF16 format)
- **Target:** .sm2 file (F16 format)
- **Conversion:** BF16 -> F16 using correct bias adjustment

The BF16 to F16 conversion formula:
```
BF16: Float = (-1)^s * 2^(be - 127) * (1 + bm/128)
F16:  Float = (-1)^s * 2^(exp - 15) * (1 + mant/1024)

Conversion: exp = be - 127 + 15 = be - 112
```

## No Bias Tensors

SmolLM2 uses **Pre-LN (Pre-LayerNorm)** architecture without bias terms:

- All projection weights are pure linear transforms (weight only, no bias)
- RMSNorm is used instead of LayerNorm (no bias)
- This is standard for modern transformer architectures
