## Mathematical Equivalence

### PyTorch Reference (Gemma/Llama style):
```python
def rms_norm(x, weight, eps):
    rms = (x.float().pow(2).mean(-1, keepdim=True) + eps).rsqrt() * x.float()
    return weight * rms
```

### C Implementation:
```c
rms = sqrt(sum(x^2) / n + eps);
output[i] = (x[i] / rms) * weight[i];
```

**Equivalence Proof:**
- PyTorch: `rms = sqrt(mean(x^2) + eps)`, then `output = x * (1/rms) * weight`
- C: `rms = sqrt(sum(x^2)/n + eps)`, then `output = x/rms * weight`
- Since `sum(x^2)/n = mean(x^2)`, these are EQUIVALENT.
