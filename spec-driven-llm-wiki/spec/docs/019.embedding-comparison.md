# Embedding Layer Implementation

**Status**: VERIFIED - Implementation matches reference

**Date**: 2026-05-29

## Overview

The embedding layer in smollm2.c converts token IDs to dense vector representations (embeddings). The model uses tied weights (input embedding = output projection/lm_head) for efficiency in small models.

## Implementation Details

### Embedding Structure

**Data Structure** (`include/smollm2.h`):
```c
typedef struct {
    int rows;
    int cols;
    uint16_t* data;  // float16 values
} sm2_tensor_f16;
```

**Model Weight** (`include/smollm2.h`):
```c
sm2_tensor_f16* tok_embeddings;  // [vocab_size, dim]
```

### Embedding Lookup Operation

Located in `src/sm2_context.c`, lines 116-122:

```c
static void embedding_lookup(float* out, int token, const sm2_tensor_f16* embed) {
    int dim = embed->cols;
    for (int i = 0; i < dim; i++) {
        uint16_t h = embed->data[token * dim + i];
        out[i] = sm2_f16_to_float(h);
    }
}
```

**Operation Summary**:
1. Input: `token` (int token ID)
2. Memory access: Read `dim` consecutive F16 values starting at `token * dim`
3. Conversion: Convert each F16 to float via `sm2_f16_to_float()`
4. Output: `float out[dim]` written to scratch buffer

**Complexity**: O(dim) per token, direct memory access (no computation)

### Token Embedding Flow

```
Token ID -> Embedding Lookup -> Float Vector [dim]
                                      |
                                      v
                            [Transformer Layers]
                                      |
                                      v
                            Final Hidden State [dim]
                                      |
                                      v
                         Final RMSNorm (final_norm)
                                      |
                                      v
                   Logits = h_final @ tok_embeddings^T
                                      |
                                      v
                            [Sampling]
```

### Weight Tying (Tied Embeddings)

The model uses tied weights where `lm_head` (output projection) shares the same weights as `tok_embeddings` (input embedding). This is common in small models to reduce parameter count.

**Logit Computation** (prefill, lines 433-446):
```c
for (int i = 0; i < model->vocab_size; i++) {
    float sum = 0.0f;
    float c = 0.0f;
    for (int j = 0; j < model->dim; j++) {
        float w_val = final_h[j] * sm2_f16_to_float(model->tok_embeddings->data[i * model->dim + j]);
        float y = w_val - c;
        float t = sum + y;
        c = (t - sum) - y;
        sum = t;
    }
    ctx->scratch.logits[i] = sum;
}
```

**Memory Layout**:
- `tok_embeddings->data` stores input embeddings: `[vocab_size][dim]` row-major
- For lm_head, we read column `j` across all rows `i`: `data[i * dim + j]`

### File Format

**Location** (`src/sm2_model.c`, lines 114-129):
```
.sm2 file structure:
  [256 byte header]
  [tokenizer section]
  [weights section at hdr->weights_offset]
      -> [4 bytes: rows]
      -> [4 bytes: cols]
      -> [rows * cols * 2 bytes: F16 data]
```

For SmolLM2-135M:
- Weights offset: 1,179,115 bytes (after header + tokenizer)
- tok_embeddings: rows=49152, cols=576
- F16 data size: 56.6 MB

### Usage in Inference

**Prefill** (`src/sm2_context.c`, line 393):
```c
embedding_lookup(ctx->scratch.x, tokens[t], model->tok_embeddings);
```

**Decode** (`src/sm2_context.c`, line 463):
```c
embedding_lookup(ctx->scratch.x, ctx->last_token, ctx->model->tok_embeddings);
```

### Memory Layout Details

```
tok_embeddings->data layout (row-major):

Token 0:   [e0_0, e0_1, e0_2, ..., e0_575]   <- offset 0
Token 1:   [e1_0, e1_1, e1_2, ..., e1_575]   <- offset 576
Token 2:   [e2_0, e2_1, e2_2, ..., e2_575]   <- offset 1152
...
Token N:   [eN_0, eN_1, ..., eN_575]         <- offset N * 576

Access pattern: embed->data[token_id * dim + dimension]
```

## Performance Notes

1. **Lookup is memory-bound**: Direct array access, no computation
2. **F16 storage**: 2 bytes per element (vs 4 for float32)
3. **Tied weights**: Saves memory but requires full forward pass for logits
4. **Scratch buffer**: Embeddings written to `ctx->scratch.x` (preallocated, no malloc in hot path)
