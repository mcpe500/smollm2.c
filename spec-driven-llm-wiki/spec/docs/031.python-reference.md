# Python Reference for SmolLM2-135M Verification

This document contains the expected behavior from the Hugging Face transformers implementation of SmolLM2-135M-Instruct.

## Setup

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model_name = "HuggingFaceTB/SmolLM2-135M-Instruct"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)
```

## Tokenization of "hello"

```python
input_ids = tokenizer.encode("hello", return_tensors="pt")
print("Tokenize 'hello':", input_ids.tolist())
```

**Result:** `[27746]`

## Logits After Forward Pass

```python
with torch.no_grad():
    outputs = model(input_ids)
    logits = outputs.logits[0, -1]  # Last position (after "hello")

print("Logits shape:", logits.shape)
print("Top 10 logits after 'hello':")
probs = torch.softmax(logits, dim=-1)
top_probs, top_ids = torch.topk(probs, 10)
for i in range(10):
    tok = tokenizer.decode([top_ids[i].item()])
    print(f"  {top_ids[i].item()}: {probs[top_ids[i]].item():.4f} '{tok}'")
```

## Multi-token Sequence Test

```python
prompt = "Once upon a time"
input_ids = tokenizer.encode(prompt, return_tensors="pt")
print("Tokenize '{}': {}".format(prompt, input_ids.tolist()))

with torch.no_grad():
    outputs = model(input_ids)
    logits = outputs.logits

print("Logits shape:", logits.shape)

# Get prediction for next token
next_logits = logits[0, -1]
probs = torch.softmax(next_logits, dim=-1)
top_probs, top_ids = torch.topk(probs, 10)
print("\nTop 10 next token probabilities:")
for i in range(10):
    tok = tokenizer.decode([top_ids[i].item()])
    print(f"  {top_ids[i].item()}: {probs[top_ids[i]].item():.4f} '{tok}'")
```

## Sampling Test

```python
# Test sampling behavior
with torch.no_grad():
    outputs = model(input_ids)
    logits = outputs.logits[0, -1]
    probs = torch.softmax(logits, dim=-1)

# Greedy (argmax)
greedy_id = torch.argmax(probs).item()
print("\nGreedy (argmax): {} = '{}'".format(greedy_id, tokenizer.decode([greedy_id])))

# Sample with temperature=0.7
temp = 0.7
logits_temp = logits / temp
probs_temp = torch.softmax(logits_temp, dim=-1)
sampled_id = torch.multinomial(probs_temp, 1).item()
print("Sampled (temp=0.7): {} = '{}'".format(sampled_id, tokenizer.decode([sampled_id])))
```
