# Spec 003: smollm2.c Performance Engineering (PE1)

## Task/Prompt

Optimize smollm2.c token generation speed to be faster than current ~600-900ms/token baseline.

## Tujuan

Mengurangi latency token generation dari ~600-900ms/token menjadi <100ms/token untuk VPS deployment.

## Current Baseline

```
Generated 10 tokens in 8866.3 ms (886.6 ms/token)
```

## Bottleneck Analysis

### Memory Bandwidth
For 135M model, each decode step reads:
- Embedding: 49152 * 576 * 2 bytes = 56MB
- Q/K/V projections: 3 * 576 * 576 * 2 = 2MB per layer
- FFN: 3 * 1536 * 576 * 2 = 5.3MB per layer
- Total per token: ~220MB weight reads

At 5 GB/s memory bandwidth: theoretical min = 44ms/token

### Compute vs Memory Tradeoff
- Current: Pure scalar ops, ~2% of peak FLOPS
- With NEON: 4x SIMD, but memory still the bottleneck
- Better approach: Cache blocking + SIMD

## Performance Engineering Plan

### PE1.1: Add NEON Backend
- File: `src/backend/sm2_backend_neon.c` (created)
- Register in `sm2_backend_ref.c`
- Use NEON for matmul (4x parallel)

### PE1.2: Cache Blocking for Weights
- Block weight matrices to fit in L2 cache
- SMOLLM2-135M: dim=576 fits in 256KB L2
- Process in blocks of 64x64 instead of full rows/cols

### PE1.3: Prefill Batch Optimization
- Process prompt tokens in batch (already sequential, but can optimize)
- Key: avoid redundant weight reads

### PE1.4: Embedding Lookup Optimization
- 49152 * 576 * 2 bytes = 56MB embedding table
- Too large for cache - need streaming read
- Use memory access patterns that help prefetcher

### PE1.2: Cache-Blocked Matmul
```c
// Block size 64 for L2 cache
#define BLOCK_SIZE 64

for (int i = 0; i < m; i += BLOCK_SIZE) {
    for (int j = 0; j < n; j += BLOCK_SIZE) {
        // Process BLOCK_SIZE x BLOCK_SIZE block
        int i_max = min(i + BLOCK_SIZE, m);
        int j_max = min(j + BLOCK_SIZE, n);
        
        for (int ii = i; ii < i_max; ii++) {
            for (int jj = j; jj < j_max; jj++) {
                // Inner loop with k
                for (int kk = 0; kk < k; kk += BLOCK_SIZE) {
                    int k_max = min(kk + BLOCK_SIZE, k);
                    // Accumulate block
                }
            }
        }
    }
}
```
