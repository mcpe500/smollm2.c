## Overview

The smollm2.c project uses a **Makefile-based build system** (no CMakeLists.txt). It is a pure C99 implementation with no external library dependencies (except standard libc and libm). The build system is designed for portability and is optimized for constrained environments like VPS with 512MB RAM.

## Build System Summary

| Aspect | Details |
|--------|---------|
| Build Tool | GNU Make |
| Language | C99 (pure) |
| Compiler | GCC (default), Clang compatible |
| Dependencies | libc, libm (standard libraries only) |
| Build Output | `smollm2-cli` (CLI executable) |

## Makefile Architecture

### Location
- Primary: `/data/data/com.termux/files/home/smollm2.c/Makefile`

### Compilation Options

```makefile
CC = gcc
CFLAGS = -std=c99 -Wall -Wextra -O3 -march=native -fomit-frame-pointer -ffast-math
CFLAGS += -DNDEBUG -Iinclude
```

**Compiler Flags:**
- `-std=c99`: C99 standard for portability
- `-Wall -Wextra`: Enable comprehensive warnings
- `-O3`: Maximum optimization level
- `-march=native`: CPU-specific optimizations
- `-fomit-frame-pointer`: Reduce stack frame overhead
- `-ffast-math`: Enable fast floating-point operations
- `-DNDEBUG`: Disable debug code
- `-Iinclude`: Include directory for headers

### Build Targets

| Target | Description | Command |
|--------|-------------|---------|
| `all` | Build smollm2-cli (default) | `make` |
| `clean` | Remove build artifacts | `make clean` |
| `check` | Syntax check all sources | `make check` |
| `help` | Show build help | `make help` |
| `smollm2d` | Build server daemon (Phase 6) | `make smollm2d` |

## Model Format (.sm2)

### File Structure

```
+------------------+
| SM2_FILE_HEADER  |  (256 bytes)
+------------------+
| tokenizer.json   |
+------------------+
| tensor_index     |
+------------------+
| weight_data      |
+------------------+
```

### Magic Number: `SM2C001`

### Supported Variants

| Variant | Layers | Dim | Hidden | Heads | KV Heads |
|---------|--------|-----|--------|-------|----------|
| 135M | 30 | 576 | 1536 | 9 | 3 |
| 360M | 32 | 960 | 2560 | 15 | 5 |
| 1.7B | 24 | 2048 | 8192 | 32 | 8 |

### Quantization Types

| Type | Description |
|------|-------------|
| `SM2_F16` | Full 16-bit float |
| `SM2_Q8_0` | 8-bit quantization |
| `SM2_Q4_0` | 4-bit quantization |
| `SM2_Q4_K` | K-quants 4-bit |

### KV Cache Formats

| Type | Description |
|------|-------------|
| `SM2_KV_F16` | Full 16-bit |
| `SM2_KV_Q8` | 8-bit quantized |
| `SM2_KV_Q4` | 4-bit quantized |
| `SM2_KV_TURBO2` | Turbo v2 format |
| `SM2_KV_MIXED` | Mixed precision |

## Tool: smollm2-convert.py

**Location**: `tools/smollm2-convert.py`

**Purpose**: Convert HuggingFace .safetensors to .sm2 binary format

**Usage**:
```bash
# Download and convert 135M model
python3 tools/smollm2-convert.py --download 135M

# Convert existing model
python3 tools/smollm2-convert.py --model model.safetensors --output model.sm2

# Specify custom tokenizer
python3 tools/smollm2-convert.py --tokenizer tokenizer.json
```

**Supported Models**:
- SmolLM2-135M-Instruct
- SmolLM2-360M-Instruct
- SmolLM2-1.7B-Instruct

## CLI Usage

```bash
# Basic inference
./smollm2-cli -m model.sm2 -p "Hello, world"

# With sampling options
./smollm2-cli -m model.sm2 -p "Hello" -t 0.7 -q 90 -n 100

# Chat mode
./smollm2-cli -m model.sm2 -p "Hello" --chat
```

### CLI Options

| Option | Description | Default |
|--------|-------------|---------|
| `-m, --model` | Model file path | Required |
| `-p, --prompt` | Input prompt | "Hello" |
| `-n, --max-output` | Max tokens | 50 |
| `-t, --temp` | Temperature | 0.7 |
| `-q, --top-p` | Nucleus sampling | 90 |
| `-k, --top-k` | Top-k sampling | 0 (disabled) |
| `-r, --rep-penalty` | Repetition penalty | 1.3 |
| `-h, --help` | Show help | - |

## Build Troubleshooting

### Common Issues

1. **Missing headers**: Ensure `include/` is in include path
2. **Architecture issues**: `-march=native` may not work on older CPUs; use `-march=x86-64` or `-march=armv8-a`
3. **Math library**: `-lm` required for math functions

### Debug Build

```bash
make clean && make DEBUG=1 CFLAGS="-g -O0 -Wall"
```

### Cross-compilation Example

```bash
make CC=aarch64-linux-gnu-gcc CFLAGS="-std=c99 -O3 -march=armv8-a"
```
