## Step 1: Pre-Attention RMSNorm (Lines 214-221)

### Formula

```
RMS = sqrt(sum(x[i]^2) / dim + eps)
output[i] = (x[i] / RMS) * weight[i]
```

Where `eps = 1e-5`.

### Implementation

```c
// Step 1: RMSNorm on x_in, write to xb_out
float sum_sq = 0.0f;
for (int i = 0; i < dim; i++) sum_sq += x_in[i] * x_in[i];
float rms = sqrtf(sum_sq / (float)dim + 1e-5f);
for (int i = 0; i < dim; i++) {
    uint16_t w = model->input_layernorm[ln_off + i];
    xb_out[i] = (x_in[i] / rms) * sm2_f16_to_float(w);
}
```

### Weight Shape
- `input_layernorm`: `[n_layers * dim]` = `[30 * 576]` = `17,280` F16 values

### Computation
1. Compute `sum_sq = sum(x_in[i]^2)` for all 576 elements
2. Compute `rms = sqrt(sum_sq / 576 + 1e-5)`
3. Normalize: `normalized[i] = x_in[i] / rms`
4. Scale: `xb_out[i] = normalized[i] * weight[i]`

### Transposed Matmul

The weight matrix is stored row-major: `q_proj[i, j] = q_proj[i * dim + j]`

To compute `Q = X @ q_proj.T`, where X is a row vector `[1, dim]`:

```c
// q = xb_out @ q_proj.T
for (int i = 0; i < dim; i++) {
    float sum = 0.0f;
    float c = 0.0f;  // Kahan compensation
    for (int j = 0; j < dim; j++) {
        float w = sm2_f16_to_float(model->q_proj[q_off + i * dim + j]);
        float y = xb_out[j] * w - c;
        float t = sum + y;
        c = (t - sum) - y;
        sum = t;
    }
    q[i] = sum;
}
```

### Kahan Summation Verification

**Standard Kahan summation formula:**
```
y = input[j] * weight - c
t = sum + y
c = (t - sum) - y = compensation for floating point error
sum = t
```

**This implementation is CORRECT.** It computes:
- `w = xb_out[j]` (input)
- `y = w * weight - c` (product minus previous compensation)
- `t = sum + y` (new sum with compensation)
- `c = (t - sum) - y` (updated compensation = rounding error)
- `sum = t`

The output `q[i]` is a scalar: the dot product of input vector `xb_out` with row `i` of `q_proj.T`, which equals column `i` of `q_proj`.

**Output shape:** `q`: `[dim]` = `[576]`

### RoPE Formula

RoPE rotates query and key vectors based on their position. For each head, dimensions are processed in pairs:

```
For dimension pair (i, i + half):
    freq = pos / theta^(2i/d)
    cos = cos(freq)
    sin = sin(freq)
    
    x0 = vec[i]
    x1 = vec[i + half]
    
    vec[i] = x0 * cos - x1 * sin
    vec[i + half] = x0 * sin + x1 * cos
```

Where:
- `theta = 100000.0`
- `head_dim = 64`
- `half = 32` (dimension pairs)
- `pos = seq_pos` (current token position)

### Implementation (from sm2_rope.c)

```c
void sm2_rope(float* q, float* k, int head_dim, int pos, int n_heads, int n_kv_heads, float rope_theta) {
    int half = head_dim / 2;
    int rope_pos = pos;

    // Apply to all Q heads
    for (int h = 0; h < n_heads; h++) {
        float* q_head = q + h * head_dim;
        for (int i = 0; i < half; i++) {
            float freq = (float)rope_pos / powf(rope_theta, (float)(2 * i) / (float)head_dim);
            float cos_theta = cosf(freq);
            float sin_theta = sinf(freq);

            float x0 = q_head[i];
            float x1 = q_head[i + half];

            q_head[i] = x0 * cos_theta - x1 * sin_theta;
            q_head[i + half] = x0 * sin_theta + x1 * cos_theta;
        }
    }

    // Apply to all KV heads
    for (int h = 0; h < n_kv_heads; h++) {
        float* k_head = k + h * head_dim;
        for (int i = 0; i < half; i++) {
            float freq = (float)rope_pos / powf(rope_theta, (float)(2 * i) / (float)head_dim);
            float cos_theta = cosf(freq);
            float sin_theta = sinf(freq);

            float x0 = k_head[i];
            float x1 = k_head[i + half];

            k_head[i] = x0 * cos_theta - x1 * sin_theta;
            k_head[i + half] = x0 * sin_theta + x1 * cos_theta;
        }
    }
}
```

### Frequency Calculation

For SmolLM2-135M (`theta = 100000`, `head_dim = 64`):

| Dimension i | Exponent (2i/d) | theta^(-2i/d) | Frequency at pos=1 |
|-------------|-----------------|---------------|-------------------|
| 0 | 0/64 = 0 | 1.0 | 1.0 |
| 1 | 2/64 = 0.03125 | 100000^(-0.03125) | 0.744 |
| 2 | 4/64 = 0.0625 | 100000^(-0.0625) | 0.554 |
| ... | ... | ... | ... |
| 31 | 62/64 = 0.96875 | 100000^(-0.96875) | 0.011 |

The frequencies decrease exponentially, encoding position in a way that decays with frequency - a key property of RoPE that enables length extrapolation.

### GQA Attention Implementation

```c
static void attention_with_cache(float* out, const float* q, int layer,
                              sm2_context* ctx, sm2_model* model) {
    int n_heads = model->n_heads;      // 9 for 135M
    int n_kv_heads = model->n_kv_heads; // 3 for 135M
    int head_dim = model->head_dim;    // 64
    int group_size = n_heads / n_kv_heads; // 3
    int kv_seq = ctx->scratch.kv_cache_len + 1; // positions to attend over

    // For each query head
    for (int qh = 0; qh < n_heads; qh++) {
        int kv_head = qh / group_size; // Maps query head to KV head

        // Compute attention scores for all cached positions
        float max_score = -1e9f;
        float scores[2048]; // Max sequence length

        // Score computation
        for (int pos = 0; pos < kv_seq; pos++) {
            float dot = 0.0f;
            for (int d = 0; d < head_dim; d++) {
                float qv = q[qh * head_dim + d];
                int cache_idx = kv_head * max_context * head_dim + pos * head_dim + d;
                float kv = ctx->scratch.k_cache[layer][cache_idx];
                dot += qv * kv;
            }
            dot *= 1.0f / sqrtf((float)head_dim); // Scale by sqrt(head_dim)
            scores[pos] = dot;
            if (dot > max_score) max_score = dot;
        }

        // Softmax (numerically stable: subtract max)
        float sum_exp = 0.0f;
        for (int pos = 0; pos < kv_seq; pos++) {
            scores[pos] = expf(scores[pos] - max_score);
            sum_exp += scores[pos];
        }

        // Weighted sum of values
        for (int d = 0; d < head_dim; d++) {
            float sum = 0.0f;
            for (int pos = 0; pos < kv_seq; pos++) {
                int cache_idx = kv_head * max_context * head_dim + pos * head_dim + d;
                float vv = ctx->scratch.v_cache[layer][cache_idx];
                sum += scores[pos] * vv;
            }
            out[qh * head_dim + d] = sum / sum_exp;
        }
    }
}
```

### GQA Mapping Table (135M)

| Query Heads | KV Head | Group Size |
|-------------|---------|------------|
| 0, 1, 2 | 0 | 3 |
| 3, 4, 5 | 1 | 3 |
| 6, 7, 8 | 2 | 3 |

### Attention Computation Per Head

For each query head `qh`:
1. **Score computation:** `dot = Q[qh] @ K[kv_head]` for all positions
2. **Scale:** `dot = dot / sqrt(64) = dot / 8`
3. **Softmax:** `softmax(scores - max)`
4. **Weighted sum:** `sum(pos, softmax_score[pos] * V[kv_head, pos])`

### Complexity Analysis

- **Standard MHA:** O(seq_len^2 * dim) per layer
- **GQA (135M):** O(seq_len^2 * kv_dim) = O(seq_len^2 * 192) vs O(seq_len^2 * 576)
- **Savings:** 3x reduction in K,V computation and cache size

## Step 11: SwiGLU Feed-Forward Network (Lines 317-358)

### SwiGLU Formula

```
gate = SiLU(gate_proj(x)) * up_proj(x)
output = down_proj(gate)
```

Where `SiLU(x) = x * sigmoid(x) = x / (1 + exp(-x))`

### FFN Structure

| Projection | Shape | Parameters per Layer |
|------------|-------|---------------------|
| `gate_proj` | `[hidden_dim, dim]` = `[1536, 576]` | 884,736 |
| `up_proj` | `[hidden_dim, dim]` = `[1536, 576]` | 884,736 |
| `down_proj` | `[dim, hidden_dim]` = `[576, 1536]` | 884,736 |

**Total FFN parameters per layer:** `3 * 884,736 = 2,654,208`

### Implementation Details (sm2_context.c Lines 317-373)

The FFN uses preallocated scratch buffer `ffn_temp` for intermediate results:
```c
float* gate_out = ffn_temp;                  // first hidden_dim elements
float* up_out = ffn_temp + hidden_dim; // second hidden_dim elements
```

**Computation flow:**
1. **Gate projection:** `gate = xb_out @ gate_proj.T` (no activation yet)
2. **Up projection:** `up = xb_out @ up_proj.T` (no activation)
3. **SiLU activation:** `gate = gate * sigmoid(gate)` - in-place on gate_out
4. **Element-wise multiply:** `gate = gate * up`
5. **Down projection:** `output = gate @ down_proj.T + residual`

### Note: Standalone FFN Module (sm2_mlp.c)

There is a standalone FFN module at `/data/data/com.termux/files/home/smollm2.c/src/sm2_mlp.c` that implements a **different SwiGLU variant**:


- `sm2_mlp.c`: `GELU(gate) * swish(up)` - applies GELU then Swish

The main implementation uses standard SwiGLU with SiLU activation only on the gate branch.

The SiLU (Sigmoid Linear Unit, also known as Swish) activation provides:
- Smooth gradient flow
- Non-monotonic behavior that adapts to input
- Self-gating property (input modulates its own activation)

## Complete Layer Forward Flow

```
Input x_in[576]
    |
    v
[Pre-Attention RMSNorm]
    | x_in normalized
    v
[Q Projection] @ Q^T  [576x576] --> q[576]
[K Projection] @ K^T  [192x576] --> k[192]
[V Projection] @ V^T  [192x576] --> v[192]
    |
    v
[RoPE] on Q and K
    |
    v
[KV Cache Store] at seq_pos
    |
    v
[GQA Attention] with KV cache
```

## Numerical Stability Considerations

### Kahan Summation in All Matmuls

Every projection matmul uses Kahan summation to reduce floating-point error accumulation:

```c
float c = 0.0f;  // Compensation
for (int j = 0; j < dim; j++) {
    float y = input[j] * weight - c;
    float t = sum + y;
    c = (t - sum) - y;
    sum = t;
}
```

**Why Kahan summation?**
- Standard FP32 accumulation has ~22-bit precision
- For 576-element dot products, error can accumulate
- Kahan summation maintains running compensation
- Error reduced from O(n * eps) to O(eps) where eps is machine epsilon

### RMSNorm Epsilon
- `eps = 1e-5` prevents division by zero
- Consistent with HuggingFace implementation

### Attention Score Scaling
- Scores scaled by `1/sqrt(head_dim) = 1/8`
- Prevents softmax saturation with large dot products

## FFN Implementation Details

### sm2_context.c (Layer Forward) - Correct SwiGLU

The actual transformer layer implementation in `src/sm2_context.c` (lines 317-373) uses standard SwiGLU:

```
gate = SiLU(input @ W_gate)
up = input @ W_up
ffn = gate * up
output = ffn @ W_down
```

**SiLU (Sigmoid Linear Unit) / Swish:** `SiLU(x) = x * sigmoid(x) = x / (1 + exp(-x))`

```c
// From sm2_context.c lines 351-357
// SiLU: gate = gate * sigmoid(gate)
for (int i = 0; i < hidden_dim; i++) {
    gate_out[i] *= 1.0f / (1.0f + expf(-gate_out[i]));
}
// Multiply: gate *= up
for (int i = 0; i < hidden_dim; i++) gate_out[i] *= up_out[i];
```

### sm2_mlp.c - Non-Standard Variant

The standalone `src/sm2_mlp.c` implements a variant with different activation:

```c
// sm2_mlp.c - Non-standard variant
gate = GELU(input @ W_gate)  // Applies GELU first
up = input @ W_up            // No activation
ffn = Swish(gate) * up      // Then applies Swish
```

**GELU:** `GELU(x) = 0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3)))`

```c
// GELU approximation from sm2_mlp.c lines 23-27
static float gelu(float x) {
    float c = SM2_M_SQRT2_M_PI;
    float t = tanhf(c * (x + 0.044715f * x * x * x));
    return 0.5f * x * (1.0f + t);
}

// Swish activation from sm2_mlp.c lines 30-32
static float swish(float x) {
    return x / (1.0f + expf(-x));
}
```

**Note:** The standalone `sm2_mlp.c` functions are provided for isolated FFN testing but are NOT used by the main transformer layer. The actual layer uses the inline implementation in `sm2_context.c`.

## RMSNorm Implementation

### Source: src/sm2_rmsnorm.c

RMSNorm differs from LayerNorm by omitting mean centering:

```
RMS = sqrt(sum(x[i]^2) / n + eps)
output[i] = x[i] * weight[i] / RMS
```

**Key properties:**
- No mean computation (unlike LayerNorm)
- Only computes RMS (root mean square)
- Learnable weight parameter for scaling
- Epsilon (`eps = 1e-5`) prevents division by zero

### Functions

```c
// Standard RMSNorm (from sm2_rmsnorm.c lines 15-29)
void sm2_rmsnorm(float* out, const float* input, const float* weight, int size, float eps) {
    float sum_sq = 0.0f;
    for (int i = 0; i < size; i++) {
        sum_sq += input[i] * input[i];
    }
    float rms = sqrtf(sum_sq / (float)size + eps);
    float scale = 1.0f / rms;
    for (int i = 0; i < size; i++) {
        out[i] = input[i] * scale * weight[i];
    }
}

// In-place variant (from sm2_rmsnorm.c lines 32-44)
void sm2_rmsnorm_inplace(float* vec, const float* weight, int size, float eps) {
    float sum_sq = 0.0f;
    for (int i = 0; i < size; i++) {
        sum_sq += vec[i] * vec[i];
    }
    float rms = sqrtf(sum_sq / (float)size + eps);
    float scale = 1.0f / rms;
    for (int i = 0; i < size; i++) {
        vec[i] = vec[i] * scale * weight[i];
    }
}
```

### SIMD Support

```c
// From sm2_rmsnorm.c lines 47-51
void sm2_rmsnorm_simd(float* out, const float* input, const float* weight, int size, float eps) {
    // Fallback to scalar (SIMD variants available per-backend)
    sm2_rmsnorm(out, input, weight, size, eps);
}
```

## RoPE Implementation

### Source: src/sm2_rope.c

RoPE (Rotary Position Embedding) encodes position by rotating query and key vectors in pairs.

### Frequency Precomputation

```c
// From sm2_rope.c lines 15-24
void sm2_rope_build_freqs(float* freqs, int n_heads, int head_dim, int max_seq, float theta) {
    for (int i = 0; i < head_dim / 2; i++) {
        float freq = 1.0f / powf(theta, (float)(2 * i) / (float)head_dim);
        for (int pos = 0; pos < max_seq; pos++) {
            freqs[pos * (head_dim / 2) + i] = freq * (float)pos;
        }
    }
}
```

### Single Vector RoPE Application

```c
// From sm2_rope.c lines 27-41
void sm2_rope_apply(float* vec, const float* freqs, int head_dim, int seq_pos) {
    int half = head_dim / 2;
    for (int i = 0; i < half; i++) {
        float freq = freqs[seq_pos * half + i];
        float cos_theta = cosf(freq);
        float sin_theta = sinf(freq);
        float x0 = vec[i];
        float x1 = vec[i + half];
        vec[i] = x0 * cos_theta - x1 * sin_theta;
        vec[i + half] = x0 * sin_theta + x1 * cos_theta;
    }
}
```

### Full RoPE (Q and K)

```c
// From sm2_rope.c lines 44-80
void sm2_rope(float* q, float* k, int head_dim, int pos, int n_heads, int n_kv_heads, float rope_theta) {
    int half = head_dim / 2;
    int rope_pos = pos;

    // Apply to all Q heads
    for (int h = 0; h < n_heads; h++) {
        float* q_head = q + h * head_dim;
        for (int i = 0; i < half; i++) {
            float freq = (float)rope_pos / powf(rope_theta, (float)(2 * i) / (float)head_dim);
            float cos_theta = cosf(freq);
            float sin_theta = sinf(freq);
            float x0 = q_head[i];
            float x1 = q_head[i + half];
            q_head[i] = x0 * cos_theta - x1 * sin_theta;
            q_head[i + half] = x0 * sin_theta + x1 * cos_theta;
        }
    }

    // Apply to all KV heads
    for (int h = 0; h < n_kv_heads; h++) {
        float* k_head = k + h * head_dim;
        for (int i = 0; i < half; i++) {
            float freq = (float)rope_pos / powf(rope_theta, (float)(2 * i) / (float)head_dim);
            float cos_theta = cosf(freq);
            float sin_theta = sinf(freq);
            float x0 = k_head[i];
            float x1 = k_head[i + half];
            k_head[i] = x0 * cos_theta - x1 * sin_theta;
            k_head[i + half] = x0 * sin_theta + x1 * cos_theta;
        }
    }
}
```

| Property | Value |
|----------|-------|
| `rope_theta` | 100000.0 |
| `head_dim` | 64 |
| Dimension pairs | 32 (indices 0-31) |
| Frequency formula | `freq = pos / theta^(2i/head_dim)` |
| Rotation | 2D rotation on dimension pairs (i, i+half) |

## Final Layer Norm (final_norm)

After all transformer layers complete, the hidden state passes through `final_norm` before computing logits with `lm_head` (shared with `tok_embeddings`).

### Purpose

The final RMSNorm:
1. **Normalizes** the final hidden state to have unit RMS
2. **Scales** the normalized vector with learnable weights
3. **Prepares** the representation for effective classification via `lm_head`

This is the last operation before the lm_head projection, ensuring the final hidden states are in a consistent range suitable for vocabulary prediction.

### Weight Shape

- `final_norm`: `[dim]` = `[576]` for SmolLM2-135M (F16, 1152 bytes)
- Single weight vector, not per-layer (unlike `input_layernorm` and `post_attention_layernorm`)

### Formula

```
RMS = sqrt(sum(x[i]^2) / dim + eps)
output[i] = (x[i] / RMS) * weight[i]
```

Where `eps = 1e-5`.

### Implementation (from sm2_context.c, lines 421-429)

```c
// Final RMSNorm
if (model->final_norm) {
    float* final_h = ctx->scratch.x;
    float sum_sq = 0.0f;
    for (int i = 0; i < model->dim; i++) sum_sq += final_h[i] * final_h[i];
    float rms = sqrtf(sum_sq / (float)model->dim + 1e-5f);
    float scale = 1.0f / rms;
    for (int i = 0; i < model->dim; i++) {
        final_h[i] = final_h[i] * scale * sm2_f16_to_float(model->final_norm[i]);
    }
}
```

### Placement in Inference Pipeline

The final_norm is applied at two points in the inference flow:

1. **Prefill phase** (`sm2_forward`): After all layers process prompt tokens
2. **Decode phase** (`sm2_decode_next`): After all layers process the newly generated token

```c
// Prefill (sm2_context.c lines 420-429)
if (model->final_norm) {
    float* final_h = ctx->scratch.x;
    // RMSNorm computation...
    for (int i = 0; i < model->dim; i++) {
        final_h[i] = final_h[i] * scale * sm2_f16_to_float(model->final_norm[i]);
    }
}

// Then compute logits
for (int i = 0; i < model->vocab_size; i++) {
    // logits[i] = final_h @ tok_embeddings[i]
}

// Decode (sm2_context.c lines 479-487)
if (ctx->model->final_norm) {
    float* final_h = ctx->scratch.x;
    // Same RMSNorm computation...
}
```

### Weight Loading (from sm2_model.c, lines 218-226)

```c
// ========== 3. Load final_norm ==========
if (fread(&r, 4, 1, f) != 1) { fprintf(stderr, "Failed to read final_norm rows\n"); return -1; }
if (fread(&c, 4, 1, f) != 1) { fprintf(stderr, "Failed to read final_norm cols\n"); return -1; }
```

### Data Layout

- **Header:** `[rows=1, cols=dim]` (4 bytes each)
- **Data:** `dim` F16 values stored in model file
- **In memory:** `dim` uint16_t values, converted to float during normalization

### Comparison with Per-Layer RMSNorms

| Property | final_norm | input_layernorm | post_attention_layernorm |
|----------|------------|-----------------|--------------------------|
| Shape | [dim] | [n_layers, dim] | [n_layers, dim] |
| Occurrences | 1 | Per layer | Per layer |
| Location | After all layers | Pre-attention | Post-attention |
| Purpose | Final normalization | Stable attention | Stable FFN |

### Role in Tie Embeddings

SmolLM2 uses **weight tying** (shared embeddings):
- `lm_head.weight = tok_embeddings.weight`

This means the final hidden states are projected back into the same embedding space to produce logits. The final_norm ensures these hidden states have appropriate magnitude before the matrix multiplication.
