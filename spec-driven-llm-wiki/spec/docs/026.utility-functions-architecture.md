# Utility Functions Architecture Documentation

## Overview

This document covers the common utility functions and math helpers used throughout the SmolLM2-C inference engine. These functions provide foundational capabilities for float16 conversion, matrix operations, activation functions, and random number generation.

---

## Float16 Conversion Utilities

### Location: `include/sm2_utils.h`

The codebase uses IEEE-754 float16 (half-precision) for weight storage to reduce memory footprint. Two complementary conversion functions handle the transformation:

### `sm2_f16_to_float()`

```c
static inline float sm2_f16_to_float(uint16_t h);
```

Converts a 16-bit half-precision float to 32-bit single-precision float.

**Implementation details:**
- Extracts sign bit (bit 15), exponent (bits 14-10), and fraction (bits 9-0)
- Handles three cases:
  - **Denormalized** (exp=0): `result = frac / 65536.0f`
  - **Infinity/NaN** (exp=31): Returns infinity or NaN
  - **Normalized** (1-30): `result = (1.0 + frac/1024) * 2^(exp-15)`

**Used in:**
- RMSNorm weight conversion
- Matmul operations (F16 weights)
- Any code reading model weights stored as F16

### `sm2_float_to_f16()`

```c
static inline uint16_t sm2_float_to_f16(float f);
```

Converts a 32-bit float back to 16-bit half-precision.

**Implementation details:**
- Uses `memcpy` to reinterpret float bits (avoids strict aliasing issues)
- Clamps overflow to infinity and underflow to zero
- Rounds fraction to nearest representable value

**Used in:**
- Weight quantization
- Model export/serialization

### Duplicate Implementations

There are additional F16 conversion functions in `src/sm2_matmul_ref.c` and `src/sm2_matmul_fast.c`:
- `f16_to_float()` (static in matmul_ref.c)
- `f16_to_f32()` (inline static in matmul_fast.c)

These serve the same purpose but are local to their respective compilation units.

## Activation Functions

### Location: `src/sm2_mlp.c`

### GELU (Gaussian Error Linear Unit)

```c
static float gelu(float x);
```

GELU(x) = 0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3)))

**Approximation used:** The fast tanh approximation instead of exact GELU formula. This is the standard GPT/GPT-2 style GELU.

**Used in:** FFN gate projection (SwiGLU architecture)

### Swish

```c
static float swish(float x);
```

Swish(x) = x * sigmoid(x) = x / (1 + exp(-x))

**Used in:** SwiGLU up projection activation

### SwiGLU Formula

The FFN combines these activations:

```
gate = GELU(x @ W_gate)
up = Swish(x @ W_up)  
down = (gate * up) @ W_down
```

## Random Number Generation

### Location: `src/sm2_sampling.c`

### xorshift64

```c
static uint64_t xorshift64(uint64_t state);
```

A fast pseudo-random number generator using the xorshift algorithm:

```c
state ^= state << 13;
state ^= state >> 7;
state ^= state << 17;
return state;
```

**Properties:**
- Period: 2^64 - 1
- Fast: only 3 XOR operations
- Not cryptographically secure (not needed for sampling)

### random_01()

```c
static float random_01(uint64_t* rng_state);
```

Returns a uniform random float in [0, 1).

```c
*rng_state = xorshift64(*rng_state);
return (float)(*rng_state >> 11) / (float)(1ULL << 53);
```

**Technique:** Takes the upper 53 bits (IEEE 754 mantissa) and normalizes to [0, 1).

## Repetition Detection

### detect_ngram_repetition()

```c
static int detect_ngram_repetition(const int* recent_tokens, int n_recent);
```

Detects immediate consecutive repetitions (ABABAB pattern). Returns count of consecutive token pairs that are identical.

**Used internally by sampling to detect degenerate output patterns.**

### sm2_apply_repetition_penalty()

```c
void sm2_apply_repetition_penalty(float* logits, int vocab_size,
                                   const int* recent_tokens, int n_recent,
                                   float penalty);
```

Modifies logits to reduce probability of repeating tokens:

```c
for each token_id in recent_tokens:
    if logits[token_id] > 0:
        logits[token_id] /= penalty;  // Reduce positive logits
    else:
        logits[token_id] *= penalty;   // Boost negative logits
```

**Effect:** Tokens that appeared recently are less likely to be selected again.

## Entropy Calculation

### compute_logits_entropy_fast()

```c
static float compute_logits_entropy_fast(const float* logits, int vocab_size);
```

Computes normalized entropy of the logits distribution.

**Algorithm:**
1. Find max logit for numerical stability
2. Extract top 64 tokens by exponential probability
3. Compute Shannon entropy: `-sum(p * log(p))`
4. Normalize by max entropy (~4.16 for 64 classes)

**Returns:** Value in [0, 1], where 0 = model is confident/fixed.

**Note:** Currently unused but available for sampling strategy decisions.

## Matrix Multiplication Utilities

### Location: `src/sm2_matmul_ref.c` and `src/sm2_matmul_fast.c`

### Dequantization

```c
static void dequant_q4_k_block(const uint8_t* qdata, const float* scale, 
                                const float* zero, float* out, int n);
```

Dequantizes a block of Q4_K (4-bit) quantized values:

```
out[i] = qval * scale + zero
```

Where qval is extracted by nibble (2 values per byte).

## Inline Optimization Patterns

### 4x Loop Unrolling

Used extensively for performance:

```c
// Instead of:
for (int i = 0; i < size; i++) {
    sum += a[i] * b[i];
}

// Unrolled 4x:
float sum0 = 0.0f, sum1 = 0.0f, sum2 = 0.0f, sum3 = 0.0f;
int i = 0;
for (; i + 3 < size; i += 4) {
    sum0 += a[i]   * b[i];
    sum1 += a[i+1] * b[i+1];
    sum2 += a[i+2] * b[i+2];
    sum3 += a[i+3] * b[i+3];
}
for (; i < size; i++) {
    sum0 += a[i] * b[i];
}
return sum0 + sum1 + sum2 + sum3;
```

**Benefits:**
- Better instruction-level parallelism
- Improved CPU pipeline utilization
- Reduced loop overhead

### Inline F16 Conversion

Using `static inline` for F16 conversion avoids function call overhead:

```c
static inline float f16_to_f32(uint16_t h) {
    // ... conversion logic ...
}
```

## Memory Safety Patterns

### Ring Buffer for Recent Tokens

```c
int* recent_tokens;  // Ring buffer
int recent_head;     // Current position
int recent_max;      // Buffer size
```

Used to track recently generated tokens for repetition penalty.

### Scratch Buffer Reuse

Preallocated scratch buffers avoid runtime malloc:

```c
float* gate = scratch;
float* up = scratch + hidden_dim;
float* ffn = scratch + hidden_dim * 2;
```

---

## Common Pitfalls

1. **F16 sign handling**: Remember to apply sign after computing magnitude
2. **Denormalized F16**: frac / 65536.0f (not 1024) for denormals
3. **Numerical stability**: Always subtract max before exp() for softmax
4. **Ring buffer bounds**: Check `idx >= 0` before array access
5. **RNG state initialization**: Must be non-zero for xorshift64
