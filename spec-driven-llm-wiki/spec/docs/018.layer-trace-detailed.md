## Test Configuration

- **Input tokens**: `[1, 28120]` (BOS + "hello")
- **Model**: SmolLM2-135M (30 layers, dim=576, hidden=1536)
- **Purpose**: Deep diagnostic to find first layer with anomalous behavior

---

## Executive Summary

### Key Findings

1. **Layer 0 shows extreme magnitude growth** (16.5x ratio) - the embedding is amplified dramatically by the first layer's RMSNorm + attention + FFN pipeline
2. **Layer 10 shows second magnitude spike** (5.5x ratio) - a second amplification event occurs mid-network
3. **Layer 28 shows near-explosion** with values reaching -1235 (WARNING flagged)
4. **Layer 29 recovers** - final layer brings magnitude back to reasonable range
5. **Final RMSNorm normalizes** hidden state to reasonable distribution
6. **Top logits are nonsensical** - "ught", "atica", "ematics", "photograp" suggest the model is producing garbage output


The embedding vector has RMS ~0.14, which after layer 0 becomes ~2.28. This is expected behavior for the first transformer layer - it expands the raw embedding into the learned feature space. **Not a bug.**

### Second Anomaly: Layer 10

```
norm_before: 4.1953
norm_after: 23.0222
ratio: 5.49
hidden state min=-93.87, max=70.02, std=23.02
```

Layer 10 shows a significant magnitude jump. Looking at the FFN projections:
- gate_min=-3.66, gate_max=4.96 (normal)
- up_min=-28.78, up_max=4.19 (slightly elevated up projection)

The FFN's up projection shows some larger values but nothing extreme. The attention scores are reasonable (attn_min=-8.44, attn_max=5.70). This appears to be a natural feature magnitude variation rather than a bug.

### Near-Explosion: Layer 28


Layer 28 shows a significant negative outlier (-1235) but the mean stays near zero (-3.12). This is likely a single problematic dimension rather than a systemic explosion. The std (53.26) is elevated but not catastrophic.

The layer recovers dramatically in layer 29 (ratio=0.21) bringing the magnitude back to normal range.

## Critical Analysis: Is Hidden State Growing Unbounded?

**Answer: NO**

The hidden state magnitude varies but does not grow unboundedly:
- Starts at 0.14 (embedding)
- Grows to ~2.3 after layer 0 (expected)
- Peaks at ~23 after layer 10 (elevated but controlled)
- Stabilizes around 5-10 for middle layers
- Ends at ~11 before final norm
- Final RMSNorm brings it to ~1.8 std

The RMSNorm is **working correctly** - it prevents runaway activation magnitudes.

## Critical Analysis: Are Attention Scores Reasonable?

**Answer: YES**

All attention scores are in reasonable range (< 50). No softmax saturation detected.

## Critical Analysis: After FFN, Is There Explosion or Vanishing?

**Answer: NO**

FFN pre-activations (gate, up projections) are within normal range. No explosion or vanishing gradients detected.

## Conclusion

The layer-by-layer trace shows that:

1. **No NaN or infinity values** anywhere in the forward pass
2. **Hidden state magnitudes are controlled** by RMSNorm
3. **Attention scores are reasonable** (no saturation)
4. **FFN activations are normal** (no explosion)
5. **Final RMSNorm works correctly**

**The forward pass is numerically stable.** The garbage output must be caused by:
- Incorrect model weights (corrupted file)
- Incorrect model architecture implementation (wrong layer order)
- Incorrect tokenizer behavior (wrong tokenization)
- Incorrect embedding handling

**Recommended next steps**:
1. Compare logits with reference Python implementation
2. Check if model file is correct (checksum validation)
3. Verify layer ordering matches HuggingFace implementation
4. Test with known-good tokenization
