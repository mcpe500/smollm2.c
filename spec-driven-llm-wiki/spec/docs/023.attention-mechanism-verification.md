## 1. Grouped Query Attention (GQA) Overview

The implementation uses Grouped Query Attention where fewer KV heads serve multiple Q heads:

| Variant | n_heads | n_kv_heads | group_size | n_layers | dim | hidden_dim |
|---------|---------|------------|------------|----------|-----|------------|
| 135M    | 9       | 3          | 3          | 30       | 576 | 1536       |
| 360M    | 15      | 5          | 3          | 32       | 960 | 2560       |
| 1700M   | 32      | 32 | 1 (MHA)    | 24       | 2048| 8192       |

**Key invariant:** `n_heads * head_dim = dim` (all variants have 64-element heads)

## 2. Query Projection

**Location:** `src/sm2_context.c` lines 223-236

```c
// Q projection: dim -> dim with Kahan summation
for (int i = 0; i < dim; i++) {
    float sum = 0.0f;
    float c = 0.0f;
    for (int j = 0; j < dim; j++) {
        float w = sm2_f16_to_float(model->q_proj[q_off + i * dim + j]);
        float y = xb_out[j] * w - c;
        float t = sum + y;
        c = (t - sum) - y;
        sum = t;
    }
    q[i] = sum;
}
```

**Output:** `q[dim]` where `q[i] = sum_j(xb_out[j] * q_proj[i, j])`

**Shape:** `[dim]` = `[n_heads * head_dim]` = `[9 * 64]` = `[576]`

**Interpretation:** Full projection produces all query heads. Q head `qh` uses elements `q[qh * head_dim .. (qh+1) * head_dim - 1]`.

## 3. Key Projection

```c
for (int i = 0; i < kv_dim; i++) {

    float c = 0.0f;

        float w = sm2_f16_to_float(model->k_proj[k_off + i * dim + j]);

        c = (t - sum) - y;

}
```

**Output:** `k[kv_dim]` where `kv_dim = n_kv_heads * head_dim`

**Shape:** `[3 * 64]` = `[192]` for 135M (vs 576 for Q)

**Interpretation:** Reduced projection because fewer KV heads. KV head `h` uses elements `k[h * head_dim .. (h+1) * head_dim - 1]`.

## 5. GQA Attention Flow

**Location:** `src/sm2_context.c` lines 128-177

###5.1 Head Mapping

```c
int group_size = n_heads / n_kv_heads;  // 3 for 135M

for (int qh = 0; qh < n_heads; qh++) {
    int kv_head = qh / group_size;  // qh 0,1,2 -> kv_head 0; qh 3,4,5 -> kv_head 1; etc.
    // ...
}
```

**Mapping table for 135M (n_heads=9, n_kv_heads=3, group_size=3):**

| Q Head (qh) | KV Head (kv_head) |
|-------------|-------------------|
| 0, 1, 2     | 0                 |
| 3, 4, 5     | 1                 |
| 6, 7, 8     | 2                 |

### 5.2 Attention Score Computation

```c
int kv_seq = ctx->scratch.kv_cache_len + 1;  // +1 for current position

for (int pos = 0; pos < kv_seq; pos++) {
    float dot = 0.0f;
    for (int d = 0; d < head_dim; d++) {
        float qv = q[qh * head_dim + d];
        int cache_idx = kv_head * ctx->params.max_context * head_dim + pos * head_dim + d;
        float kv = ctx->scratch.k_cache[layer][cache_idx];
        dot += qv * kv;
    }
    dot *= 1.0f / sqrtf((float)head_dim);  // Scale by 1/sqrt(64) = 0.125
    scores[pos] = dot;
}
```

**Query access:** `q[qh * head_dim + d]` - extracts d-th element of qh-th query head

**Key access:** `k_cache[layer][kv_head * max_context * head_dim + pos * head_dim + d]`

### 5.3 Cache Indexing Formula

```c
int cache_idx = kv_head * ctx->params.max_context * head_dim + pos * head_dim + d;
```

Maps to flat array layout: `[kv_head][pos][d]` with stride = `max_context * head_dim`.

###5.4 Softmax with Numerical Stability

```c
float max_score = -1e9f;
for (int pos = 0; pos < kv_seq; pos++) {
    if (scores[pos] > max_score) max_score = scores[pos];
}

float sum_exp = 0.0f;
for (int pos = 0; pos < kv_seq; pos++) {
    scores[pos] = expf(scores[pos] - max_score);  // Numerical stability
    sum_exp += scores[pos];
}
```

### 5.5 Weighted Sum

```c
for (int d = 0; d < head_dim; d++) {
    float sum = 0.0f;
    for (int pos = 0; pos < kv_seq; pos++) {
        int cache_idx = kv_head * ctx->params.max_context * head_dim + pos * head_dim + d;
        float vv = ctx->scratch.v_cache[layer][cache_idx];
        sum += scores[pos] * vv;
    }
    out[qh * head_dim + d] = sum / sum_exp;
}
```

## 6. RoPE Application

**Location:** `src/sm2_rope.c` lines 44-80

RoPE is applied to both Q and K after projection:

```c
void sm2_rope(float* q, float* k, int head_dim, int pos, int n_heads, int n_kv_heads, float rope_theta) {
    for (int h = 0; h < n_heads; h++) {
        float* q_head = q + h * head_dim;
        // Apply rotation to each half of the head
        for (int i = 0; i < half; i++) {
            float freq = (float)rope_pos / powf(rope_theta, (float)(2 * i) / (float)head_dim);
            // Rotate: x0*cos - x1*sin, x0*sin + x1*cos
        }
    }
    for (int h = 0; h < n_kv_heads; h++) {
        float* k_head = k + h * head_dim;
        // Same rotation for keys
    }
}
```

**Key point:** RoPE is applied independently to all Q heads (n_heads) and all K heads (n_kv_heads).

## 8. Attention Kernel Variants

The codebase includes alternative attention implementations in `src/attention/`:

### 8.1 Flash Attention (`sm2_attn_flash_prefill.c`)
- Online softmax computation
- Tile-based processing (64-element tiles)
- O(n) memory complexity vs O(n^2) naive

### 8.2 Paged Attention (`sm2_attn_paged.c`)
- Reads from page-structured KV cache
- Uses `sm2_kv_pool` and `sm2_kv_table` structures
- 16-token page size (`SM2_KV_PAGE_TOKENS`)

### 8.3 Prefill Attention (`sm2_attn_prefill.c`)
- Full attention over prompt tokens
- Supports variable sequence length
- Sequential position processing

**Note:** The main inference path in `sm2_context.c` uses the inline `attention_with_cache()` function rather than these kernel variants.

## 10. Critical Bugs Found

### BUG #1: scores[2048] Array Overflow (CRITICAL)

**Location:** Line 144
```c
float scores[2048];
```

**Problem:** max_seq = 8192, but scores array only has 2048 elements.

**Impact:**
- Sequences with kv_seq > 2048 will overflow the stack buffer
- Causes undefined behavior, memory corruption

**Fix:**
```c
float scores[8192];  // Match max_seq
```

---

### BUG #2: max_context vs max_seq Mismatch (CRITICAL)

**Location:**
- `src/sm2_context.c` lines 150, 170, 275 (cache indexing)
- `src/smollm2.c` line 129 (parameter override)

**Problem:**
1. KV cache allocated with `max_seq` (line 48):
   ```c
   size_t kv_per_layer = (size_t)model->n_kv_heads * max_seq * model->head_dim;
   ```
2. `max_context` CORRECTLY set to `max_seq` during context creation (line 68):
   ```c
   ctx->params.max_context = max_seq;  // 8192
   ```
3. BUT then OVERRIDDEN in `smollm2.c`:
   ```c
   ctx->params.max_context = args->ctx_size;  // Default 2048!
   ```
4. Cache indexing uses this overridden value, causing out-of-bounds access

**Impact:** For sequences > ctx_size, KV heads1+ access wrong cache regions.

**Fix options:**
1. Remove the override in `smollm2.c`
2. Use `max_seq` directly in cache indexing
3. Add validation: `if (args.ctx_size > max_seq) args.ctx_size = max_seq;`

## 12. Memory Layout Summary

**Q buffer:** `[dim]` = `[n_heads * head_dim]`
```
[Q_head_0][Q_head_1]...[Q_head_n-1]
```

**K/V buffers:** `[kv_dim]` = `[n_kv_heads * head_dim]`
```
[KV_head_0][KV_head_1]...[KV_head_n-1]
```

**KV Cache per layer:** `[n_kv_heads * max_seq * head_dim]`
```
[KV_head_0]: [pos_0][pos_1]...[pos_max_seq-1]
[KV_head_1]: [pos_0][pos_1]...[pos_max_seq-1]
...
```

**Attention output:** `[dim]` = `[n_heads * head_dim]`
```
[Out_head_0][Out_head_1]...[Out_head_n-1]
```
